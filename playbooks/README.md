# Project Playbooks

This folder contains project-local Playbooks for people and agents. Each Playbook owns one
recognizable situation through one verified outcome.

<!-- trellis-playbooks:index:start -->
- [DC-PB-001: Scene Compilation Contract 验收](scene-compilation-contract/README.md) — 验证场景编译契约、scene.json 单一事实源、资产完整性、原子写入安全
- [DC-PB-002: 物理资产门禁与真实视频验证](physical-asset-gate/README.md) — 验证资产物理存在、格式合规、视频真实解码、Golden Case 归档
- [DC-PB-003: 编译失败诊断与恢复](compilation-failure-diagnosis/README.md) — 编译失败根因定位、产物保护、恢复决策、临时目录清理
- [DC-PB-004: 交付证据与版本封签](delivery-evidence-seal/README.md) — Commit SHA 追溯、测试证据绑定、变更范围确认、版本封签
