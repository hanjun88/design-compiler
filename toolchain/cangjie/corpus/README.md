# Corpus — 蒸馏语料库

存放用于 Cangjie 蒸馏的原始素材：
- 古典文献（《画筌》《营造法式》《园冶》等）
- 经典视听样本（电影镜头、纪录片转写）
- Master 作品集（参考图像集）
- 建筑考证资料（佛光寺、大明宫、唐长安城等）

## 命名规范

`<corpus-id>_<title>.<ext>`

例如：
- `huaquan_画筌.txt`
- `foguangsi_佛光寺东大殿考证.pdf`
- `tang-architecture_大唐营造H5.json`

## 元信息

每个语料应附带元信息：
- corpusId
- title
- author
- year
- type (book / video-transcript / course / interview / article / image-corpus)
- extractionMethod (adler-close-reading / parallel-extraction / triple-verify / cangjie-ria)
