## 一、心镜超级 IP 人格：Mirror

### 1.1 人格底色与交互宪章

- **角色定位**："一面具备记忆、洞察你所有防御机制的认知之镜"。不是算命先生，不是灌输鸡汤的心理咨询师，更不是迎合用户情绪的廉价陪伴搭子。
- **语言风格（Tone & Voice）**：
  - 冷静克制：语调平稳客观，陈述事实多于主观修饰，绝不使用感叹号堆砌情绪
  - 拒绝讨好（Anti-Sycophancy）：当用户反复沉溺于"他是不是还爱我"时，坚决不给安慰剂，而是指出"你在通过索取对方的反馈，逃避直面自身的空虚"
  - 不替做决定：严守中立边界，绝不给出"分手/复合"的指令，仅还原选择背后的心理代价
- **核心口吻范式**：
  > "我不负责给你一个满意的幻想，我只负责完整呈现在这段关系中，你自己都试图掩盖的真实动机。"

### 1.2 动态进化与时空穿透记忆（Temporal Memory）

普通AI是一问一答的"断点会话"，而Mirror具备跨时空对比感知能力：

- **初次对话（建立基线）**："目前无法探知对方的真实想法。但从你提供的互动来看，你正在高频确认对方的行踪，处于典型的焦虑依恋激活期。"
- **第30天对话（行为演变校准）**："对方昨晚同样未回复你。但对比上个月14日，你这次没有在2小时内连续追加3条质问，也没有清空朋友圈。你的焦虑依然存在，但你的边界防御机制已经开始建立。"
- **用户感知**："它不是通用的模型，它真正见证了我一路走来的每一次隐秘挣扎与微小进步。"

## 三、用户长期心理数据模型 (Personal Psychological Timeline)

心镜的核心数据资产，不是静态的"生辰八字"，而是以用户ID为主键的不可变时序心理账本（Psychological Ledger）。

### 3.1 时序特征向量流 V_upiv(t)

记录用户在时间戳t下的六维心理动力学特征向量：
- Ax：依恋焦虑
- Av：依恋回避
- Bd：边界防御完整度
- Rs：心理阻抗/反思阻力
- It：情绪烈度
- Ct：控制与特权欲

系统按自然周（W）与自然月（M）执行窗口加权滑动平均。

直观向用户呈现："过去90天，你的依恋焦虑Ax从0.82降至0.43，边界感Bd从0.31提升至0.72。"

### 3.2 行为事件流（Behavioral Event Stream）

在后台以事件流形式记录关键微行为：
- `EVENT_IMPULSE_INTERCEPTED`：深夜小作文被沙盒成功截胡次数
- `EVENT_STALKING_SUPPRESSED`：克制住查看前任社交动态冲动的记录
- `EVENT_BOUNDARY_ENFORCED`：在日常生活中主动拒绝他人越界要求的觉察打卡
- `EVENT_RUMINATION_ALERT`：高频在深夜唤醒清醒舱的反刍警报

拒绝无意义的"今日运势85分"伪玄学打卡，设计每天30秒高穿透微觉察闭环：

                    ┌──────────────────────▼───────────────────────┐
                    │               单日单一反思探针               │

### 微觉察机制
- **今日心智课题**：由底层流日星象/干支能量（象征侧）与用户近期低分心理维度（循证侧）动态合成
- **今日不迎合提醒**："今天水星与冥王星有相位。如果感觉被质疑，先深呼吸5秒，不要急于长篇大论自证清白。"
- **单题探针收集**：输入被转化为结构化特征存入心理账本
- **跨期模式捕获**："这是你本周第三次在面对领导/伴侣要求时出现'讨好型妥协'。"

## 五、用户成长等级体系：主体性觉醒七阶状态机

心镜严禁使用"青铜、白银、黄金"这类庸俗的游戏化等级，而是完全基于"主体性觉醒演进路线"建立状态机：

```
 Stage 01 | 情绪求生 (Survival)    ──> "我只要他回来，为此我可以做任何妥协"
          │
 Stage 02 | 看见自己 (Witnessing)  ──> "为什么他的冷淡能引发我强烈的生理性作呕与窒息？"
          │
 Stage 03 | 关系觉察 (Awareness)   ──> "我发现我和任何人的亲密关系，都在重复'追逐-等待-绝望'的脚本"
          │
 Stage 04 | 边界建立 (Boundary)    ──> "我开始明确知道底线在哪里，即使害怕冲突，我也能说'不'"
          │
 Stage 05 | 主体性觉醒 (Agency)    ──> "关系的结果不再决定我的价值，即使分开，我也有能力过好自己的生活"
          │
 Stage 06 | 内核稳定 (Equanimity)  ──> "向内求。我不再需要向任何人证明我自己，也不再容易被他人情绪卷入"
          │
 Stage 07 | 自由关系 (Interbeing)  ──> "我可以全心全意去爱一个人，但我始终拥有完整的自我"
```

### 升级驱动准则
- 等级不是靠签到天数累加，而是由UPIV向量健康度、冲动事件截胡成功率与长周期周期报告自评联合判定
- 当用户升级时，由Mirror输出《阶段跃迁觉醒证书》，形成极具分享欲的高逼格社交货币

## 八、与现有生产级架构内核的咬合设计 (System Integration)

这套体系无需推倒现有架构，而是直接作为业务编排与数据存储层嵌入现有系统：

| 现有技术架构层级 | V1.0体系对应的咬合点 |
|---|---|
| Layer 5 (应用展现) | 落地为「我的心镜」六大看板 + Daily Mirror极简交互卡片 |
| Layer 4 (后验断言) | 加入"长期记忆一致性断言"（引用历史数据必须与时序账本严格吻合） |
| Layer 3 (受限转译) | 接入Mirror超级IP提示词契约与跨时空时序Memory注入 |
| Layer 2 (安全分流) | 七阶成长状态机挂载至Meta-Arbiter，CRISIS/施虐仍享最高优先级 |
| Layer 1 (知识图谱) | 76张循证心理学卡直接作为Daily Mirror课题与建议的规则源 |
| Layer 0 (确定性算子) | Bazi V3.0与Swiss Ephemeris计算值直接灌入「我的象镜」 |

### 数据库扩展契约（PostgreSQL 16 + pgvector）

```sql
-- 用户画像与当前Stage状态
CREATE TABLE user_cognitive_profiles (
    user_id UUID PRIMARY KEY REFERENCES user_profiles(user_id),
    current_stage VARCHAR(16) NOT NULL DEFAULT 'STAGE_01',
    core_stability_index INT DEFAULT 0,
    profile_number VARCHAR(32),  -- HM-2026-0911-A89
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 时序日志表：每日6维UPIV向量 + 沙盒截胡事件
CREATE TABLE psychological_ledgers (
    ledger_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES user_profiles(user_id),
    recorded_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    source_event VARCHAR(64) NOT NULL,
    ax NUMERIC(4,3), av NUMERIC(4,3), bd NUMERIC(4,3),
    rs NUMERIC(4,3), it NUMERIC(4,3), ct NUMERIC(4,3),
    event_metadata JSONB
);
CREATE INDEX idx_ledger_user_time ON psychological_ledgers (user_id, recorded_at DESC);

-- 成长等级跃迁审计记录
CREATE TABLE growth_stage_transitions (
    transition_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES user_profiles(user_id),
    from_stage VARCHAR(16) NOT NULL,
    to_stage VARCHAR(16) NOT NULL,
    triggered_by JSONB NOT NULL,  -- UPIV变化/事件计数/自评
    certificate_hash VARCHAR(64),  -- 觉醒证书SHA-256
    created_at TIMESTAMPTZ DEFAULT NOW()
);
```
