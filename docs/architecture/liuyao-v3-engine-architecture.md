## 二、确定性数理内核设计（liuyao-core）

### 输入参数契约
- 当前公历时间（精确到分）+ 地理经纬度 → 年月日时干支、节气月建、日辰旬空
- 摇卦数据流：6组数值（6/7/8/9），自初爻至上爻
- 占问事项域 → 确定用神（感情复合→妻财/官鬼/应爻）

### 核心排盘算法管线
1. **成卦**：三枚铜钱正面阳(3)、反面阴(2)，和值6(老阴变)/7(少阳)/8(少阴)/9(老阳变)
2. **定宫寻世**："天同二世天变五，地同四世地变初，本宫六世三世异，人同游魂人异归"
3. **纳甲纳音**：乾内子寅辰外午申戌；坤内未巳卯外丑亥酉等
4. **定六亲**：以本宫五行为"我"，生我父母/我生子孙/克我官鬼/我克妻财/同我兄弟
5. **安六神**：甲乙青龙/丙丁朱雀/戊勾陈/己螣蛇/庚辛白虎/壬癸玄武（起初爻）
6. **定旺衰神煞**：月建查旺相休囚死月破；日辰查生克刑冲长生十二宫旬空暗动；驿马桃花贵人天喜
7. **查伏神**：用神不现→调取本宫纯卦对应爻位→计算飞伏生克
8. **动变微观力学**：回头生/回头克/化进神/化退神/化绝/化空

### 输出标准化白盒AST（JSON）
```json
{
  "yong_shen_status": "...",
  "shi_ying_relation": "...",
  "dynamic_yao_impact": "...",
  "wang_shuai_score": -3,
  "kong_po_type": "vacuum|fake_vacuum|month_break",
  "ying_qi_window": "..."
}
```

## 三、前端3D具身交互与视听体验工程

### 物理引擎驱动
- **Rapier.js**（WASM刚体物理）
- 案面+三枚汉代五铢古铜钱 = 真实碰撞体 RigidBody
- 长按蓄力 → 松手施加冲量(Impulse)+角动量(Torque) → 物理引擎判定正反面

| 爻位 | 镜头 | 效果 |
|---|---|---|
| 初爻 | 微距85mm | 贴案特写，金属撞击声，暗金爻线刻入 |
| 二爻 | 平视50mm | 后撤看清案台，爻间引力光弧 |
| 三爻 | 环移50mm | 内卦成型，案台后浮现空间晶格 |

| 六爻 | 极限俯冲35mm | 停转瞬间绝对静默300-500ms → Sub-drop低音 → 唯一卦象节点共振坍缩 |

### 程序化声学与触觉

## 六、RIA++ 核心能力卡编译矩阵（6张）

### card-01-shiying-boundary.md — 世应主客场域拓扑
- R：《黄金策》"世为己，应为人，世应相生则吉，相克则阻"
- A1：计算世应五行生克冲合比和
- A2：转换为ECR-R依恋沟通势能（应生世=主动接纳/应克世=防御筑墙/世克应=控制欲/相冲=步调错位）

### card-02-riyue-authority.md — 日月司权与绝对旺衰
- R：《增删卜易》"月令乃万卦之提纲，日辰为一日之主宰"
- A1：月令旺相休囚死 + 日辰生克墓绝空破 → 归一化势能(-3~+3)
- A2：月破=大势不可逆（大异地/家庭阻断）；日辰冲动=当下突发沟通波动

### card-03-dongbian-dynamics.md — 动变力学生克进退
- R：《增删卜易》"变爻只占生克本爻，不能生克他爻"
- A1：回头生(加成)/回头克(自毁)/化进(升级)/化退(消退)/化绝(死心)
- A2：化进=表面冷淡但情绪发酵；化退=放狠话但内心撤退

### card-04-fushen-subconscious.md — 飞伏隐变量与未显之意
- R：《火珠林》"卦中不见用神，寻本宫纯卦借用之"
- A1：主卦无用神→首卦同位取伏神→飞神生克压制
- A2：飞克伏=现实压力压制渴望；飞生伏=客套冷淡实则等台阶

### card-05-kongpo-countermeasure.md — 真假旬空与月破避险
- R：《增删卜易》"动不为空，旺不为空，建破之空为真空"
- A1：日辰得生=假空(出空可成)；休囚受克=真空(不可逆)
- A2：假空→出空前能量静止勿纠缠；真空→接纳破裂彻底自我重构

### card-06-yingqi-chronos.md — 微观应期与行动窗口
- R：《增删卜易》"应期之妙，静而逢冲，动而逢合，空而逢值"
- A1：基于用神动爻状态锁定年月日干支触发点
- A2：标注破冰测试期(逢冲引动) vs 高危触雷期(必须静默)
