## 二、用户生命周期与8级"毕业机制"（Stage 0 ~ Stage 7）

心镜衡量成功的终极标准不是停留时长（Time Spent），而是主体性恢复速度与毕业率：

| 阶段 | 定义 | 用户核心心智状态 | 系统介入动作 | 关键毕业指标 |
|---|---|---|---|---|
| Stage 0 | 急性危机 | "我现在极度痛苦，无法思考" | SOS情绪急救、呼吸着陆、12356硬熔断 | 躯体激活度降至安全阈值以下 |
| Stage 1 | 冲动截胡 | "我想发长篇小作文质问TA" | 发泄沙盒模拟、NVC拆解、Logit偏置冷设防 | 成功阻止破坏性沟通≥3次 |
| Stage 2 | 模式识别 | "为什么我总是在重演这种悲剧？" | 全维报告、依恋与戈特曼四骑士模式切片 | 能准确复述自身防御策略 |
| Stage 3 | 触发觉察 | "TA一冷淡，我立刻就陷入抓狂" | 晨间微胶囊、情绪触发日记 | 情绪触发时出现≥10分钟行为停顿 |
| Stage 4 | 边界建立 | "我不知道该不该答应TA的不合理要求" | 拒斥话术演练、课题分离边界卡 | 独立完成≥1次温和拒绝 |
| Stage 5 | 价值内收 | "我需要TA的认可来确认自身存在" | 自尊强化练习、沉没成本剥离 | 连续14天无需外部确认即可平稳生活 |
| Stage 6 | 独立决断 | "我不知道是该复合还是彻底离开" | 决策树推演、非依赖性抉择引导 | 独立做出关系去留决策且不反刍 |

### 1. ACQUISITION OS（获客与流量引流）
- **用户旅程**：公域社交媒体（小红书/知乎）→ 情感冲突切片/命理好奇 → 扫码进入自测
- **产品模块**：场景化公域探针（"冷暴力解构"、"复合可行性推演"、"八字十神看亲密模式"）
- **核心算法**：公域触达意图分类器，识别"急性创伤"与"常规好奇"
- **AI职责**：无（纯静态文案与结构化题库，杜绝获客阶段幻觉承诺）
- **KPI**：扫码率、落地页首屏激活率（目标>35%）
- **技术**：Cloudflare Edge + Next.js 15静态渲染（SSG）
- **伦理边界**：严禁"包挽回"、"100%命中"，明示为个人认知探索工具

### 2. COGNITIVE OS（认知计算与仲裁）
- **用户旅程**：输入时空出生参数与互动信息 → 底层引擎计算 → 映射为统一认知向量
- **产品模块**：Bazi V3.0、Astrology V3.0、Psychology Engine、Meta-Arbiter v2.0
- **核心算法**：太阳黄经连续插值、Swiss Ephemeris历算、UPIV 6维投影、五级不可逆状态机
- **数据结构**：GroundTruthIR、SymbolicPsychMappingRegistry、UPIVVector
- **AI职责**：受限转译，仅读取经Arbiter仲裁后的IR结构填充模板，禁止自主推论
- **KPI**：单次推演时延<50ms，断言失败率<0.1%
- **技术**：Python 3.12 (FastAPI) + C扩展原生动态库（pyswisseph）
- **伦理边界**：象征系统置信度硬锁[0.36,0.40]，冲突时循证心理学拥有绝对仲裁否决权

### 3. EXPERIENCE OS（核心产品体验）
- **用户旅程**：30秒3题情境力场自测 → 即时Micro-Insights → 解锁深度选项
- **产品模块**：30秒力场探针（Micro-Discovery）、互动关系报告
- **核心算法**：情境题库动态分支算法、基于选项的行为倾向打标器
- **AI职责**：根据预制知识卡片动态匹配认知反转金句（Aha-Shift）
- **商业模式**：低客单解锁（¥19~¥69单项自测与报告）
- **KPI**：30秒自测完答率（目标>80%）、初级报告购买转化率（目标>12%）
- **技术**：React 19 + Framer Motion，轻量端侧状态机
- **伦理边界**：不强制注册，不读通讯录，极简数据索取

### 4. HEALING OS（疗愈与急救 / MindMirror Stabilization System）
- **用户旅程**：深夜情绪过载 → SOS Chamber → 发泄沙盒模拟发送小作文 → 获得解构阻断
- **产品模块**：首夜发泄沙盒（Fake Chat Sandbox）、13步躯体着陆指南、NVC结构拆解器
- **核心算法**：非暴力沟通四要素解析、对冲性冷设防Logit偏置算法、反事实动态模拟
- **AI职责**：Shadow Agent模拟（以冷淡、设立边界为特征，打破讨好幻想，阻断冲动）
- **商业模式**：成长陪伴月卡核心权益（¥59/月）
- **KPI**：高危冲动截胡率（"今晚未发送"确认率>85%）
- **技术**：WebSocket双向流式通信，Redis 7.2内存状态管理（15分钟TTL物理覆盖）
- **伦理边界**：自残他伤倾向立即切断对话，弹出国家心理援助热线（12356）

### 5. AGENCY OS（主体性重塑）
- **用户旅程**：脱离急性痛苦 → 6维心理能力评估 → 8周自主性重构计划
- **产品模块**：Core Psychological Capability Map、边界训练场、课题分离练习器
- **核心算法**：主体性成长指数追踪算法、行为作业反馈评分器
- **AI职责**：苏格拉底式提问引导者，绝不提供现成决定，只追问"你的感受与边界是什么"
- **商业模式**：高阶主体性训练营 / 1v1顾问复核服务（¥399起）
- **KPI**：阶段作业完成率、主动求助频率下降斜率
- **技术**：PostgreSQL 16长期演化轨迹存储，事件溯源架构（Event Sourcing）
- **伦理边界**：绝不制造情感依赖，检测到过度频繁寻求决策时主动触发冷却期

### 6. GROWTH OS（长期生命系统 & DTC实体信物）
- **用户旅程**：完成成长周期（如通过Stage 5）→ 成长印记勋章 → 独立站选择信物 → 每日晨间觉察微胶囊
- **产品模块**：晨间能量微胶囊（Daily Capsule）、Life Architecture报告、HeartMirror Store独立站
- **核心算法**：当日天象与命理节律同频分析引擎（仅输出心智觉察提示，不输出吉凶断语）
- **AI职责**：生成针对当日心理焦点的微练习（Symbolic Ritual → Behavioral Practice）
- **商业模式**：年度全能会员（¥598/年）、DTC激光微雕信物（纯POD一件代发）
- **KPI**：月卡次月留存率、信物复购与留存纪念率
- **技术**：Shopify/自建独立站（独立域名与独立收银台，与核心诊断物理分离）+ 激光工厂API
- **伦理边界**：严禁信物"转运、复合、避灾"功效宣传；信物仅为"走完一段成长功课的物理记忆锚点"

## 四、双轨架构：主应用与DTC独立站物理隔离

```
                    HEARTMIRROR UNIVERSE
                              │
         ┌────────────────────┴────────────────────┐
         ▼                                         ▼
   MindMirror App                           HeartMirror Store
 (mindmirror.ai / App)                     (store.heartmirror.com)
┌─────────────────────────────┐           ┌─────────────────────────────┐
│ 业务定性：认知诊断与心理成长 │           │ 业务定性：成长仪式与实体记忆 │
│ 属性：数字工具、严肃陪伴   │           │ 属性：独立电商品牌、POD工艺 │
│ 核心价值：主体性觉醒       │           │ 核心价值：阶段成长印记     │
│ 严禁：任何商品橱窗推销     │           │ 严禁：任何运势/功能性玄学宣传 │
└──────────────┬──────────────┘           └──────────────┬──────────────┘
               │                                         │
               └────────── 统一用户身份体系 ──────────────┘
                         (JWT / OAuth 2.0)
```

**入口触发逻辑**：用户在MindMirror App中只有完成阶段性认知作业（如连续14天情绪着陆并完成边界测试）时，系统才掉落专属成长印记Hash，凭此Hash前往HeartMirror Store兑换定制信物。未完成成长的用户在主应用内无法直接访问购物商城。
