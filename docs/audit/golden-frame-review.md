## 4. 渲染源码参数（从 `render-pipeline.bundle.js` 提取）

### 4.1 清屏色

```javascript
gl.clearColor(0.05, 0.1, 0.15, 1);
```

量化为 8-bit: R=round(0.05*255)=13, G=round(0.1*255)=26, B=round(0.15*255)=38
**实际清屏色 = [13, 26, 38, 255]**

### 4.2 黄金帧参考网格

```javascript
id: "golden-frame-reference",
coordinateSpace: "camera",
primitiveType: "triangles",   // 注意：是 triangles，不是 POINTS
vertices: [
  { x: 0,    y:  0.8, z: 0, r: 0.9, g: 0.2, b: 0.2 },  // top: red
  { x: -0.8, y: -0.6, z: 0, r: 0.2, g: 0.8, b: 0.2 },  // bottom-left: green
  { x:  0.8, y: -0.6, z: 0, r: 0.2, g: 0.2, b: 0.8 }   // bottom-right: blue
],
indices: [0, 1, 2],
shader: "standard" (outputs interpolated vertex color)
```

### 4.3 关键事实

- **图元类型**: `triangles`，存在重心插值，**非** `gl.POINTS`
- **着色器**: 输出插值顶点色，存在次像素混合
- **因此**: "零光栅化边框误差 E_rasterization ≡ 0" 的断言**不成立**，因为使用的是三角形而非点图元

## 7. 审阅结论

### 7.1 可确认项

1. **资产完整性**: golden-frame.rgba.bin 精确为 320x240x4=307,200 字节，SHA-256 与存储值一致。
2. **清屏色与源码一致**: 实测 [13,26,38] 匹配 `clearColor(0.05, 0.1, 0.15, 1)`。
3. **三角形渲染存在**: 1,980 非背景像素形成中心 66x58 三角形区域，颜色从红→绿→蓝平滑插值，与顶点定义一致。
4. **Alpha 通道**: 全部不透明（255），符合预期。
5. **PNG 与 RGBA bin 共存**: 两个资产文件均存在。

### 7.2 不可确认项 / 存在问题

1. **实现方审阅卷宗的预期像素值全部错误**: 清屏色、中心像素、图元类型的声明均与源码和实测不符。该卷宗不能作为像素级断言的依据。
2. **渲染语义正确性未验证**: `verify-golden-frame.js` 不检查具体像素值，无法证明三角形顶点位置、MVP 变换、裁剪行为正确。
3. **无独立重渲染对账**: 未在当前环境重新执行 WebGL2 渲染并与 golden frame 做逐像素 diff，无法证明该 golden frame 是当前源码的确定性输出。
4. **三角形尺寸异常小**: 相机空间顶点 (±0.8, ±0.6) 投影后仅占 66x58 像素，需确认投影矩阵参数是否符合设计预期。

### 7.3 裁定

**RENDER-07C: PARTIAL PASS — 资产完整性确认，渲染语义正确性未充分证明**

- 资产物理完整性、哈希绑定、字节格式：**PASS**
- 实现方卷宗的像素级预期值：**REJECTED（与源码和实测不符）**
- 渲染管线语义正确性（MVP、裁剪、插值）：**NOT VERIFIED（缺少独立重渲染对账）**
- 本审阅**不**构成 REV-13 工具链封签或 STEP 5.2-B/5.2-C 解锁依据。
