# 创伤康复多路径选择：EMDR / 躯体疗法 / 正念 / 创意治疗的循证分层

## I — 义理与心理学对齐（Interpretation）
创伤康复不是只有一条路，而是一个**循证分层的路径谱**：
1. **一线（证据最强）**：创伤聚焦 CBT（含暴露疗法 ET）与 EMDR，两者疗效大致相当（L00387-L00389）。EMDR 不只是眼动——它同时让来访者关注躯体感觉、想法和情绪，类似正念（L00406），眼动本身并非必要成分（L00408）。
2. **二线/辅助（证据增长中）**：正念冥想、躯体感觉技术（sensorimotor）、情绪聚焦疗法、DBT/ACT（L00483-L00484）。Cloitre 专家共识将情绪调节列为一线，正念/冥想列为二线。
3. **补充/探索性（证据有限但有前景）**：瑜伽、针灸、催眠、艺术/音乐治疗、戏剧/表达性治疗（L00450）。这些作为 adjunct（辅助）使用，不替代一线。
4. **关键顺序原则**：先稳定化/情绪调节，再创伤加工。对非西方文化或高躯体化人群，先教肌肉放松/冥想等情绪调节技能，再上暴露（L00415）——这与 CPTSD 书的"先安全后加工"完全一致。
van der Kolk 强调的核心立场：**语言叙事疗法对无法用语言言说的躯体创伤有局限**，因此需要躯体取向（瑜伽/神经感觉/EMDR 的躯体关注）作为补充。

## A1 — 判定算法与 AST 证明节点
1. 评估来访者当前阶段：急性危机/稳定化期 vs 稳定后加工期；
2. 稳定化期优先：情绪调节（呼吸/放松/正念）+ 安全计划，不急于暴露；
3. 加工期可选一线：TF-CBT/ET 或 EMDR（疗效相当，按来访者偏好与可及性选择）；
4. 辅助叠加：瑜伽/躯体感觉/创意治疗作为 adjunct，不作为唯一治疗；
5. 文化适配：高躯体化/非西方背景先教情绪调节技能再暴露。
AST 节点：`acute/crisis → stabilization (emotion regulation + safety) → processing (TF-CBT/EMDR) → adjunct (yoga/sensorimotor/creative) → reintegration`。

## A2 — 业务场景与 NVC 提示
**触发语**："EMDR 有用吗？"｜"瑜伽/冥想能治创伤吗？"｜"哪种心理治疗对 PTSD 最有效？"｜"我做了几年谈话治疗但身体还是紧，还有别的办法吗？"｜"神经反馈/艺术治疗靠谱吗？"。
- 场景① 用户问治疗选择：按证据分层回答，不吹不黑。
- 场景② 谈话疗法卡住时：提示躯体取向（EMDR 的躯体关注/瑜伽/传感器官技术）可能补充语言无法触及的部分。
- 与相邻卡区分：
  - 与 `tf-cbt-emdr`（现有卡）：本卡是**全路径谱**（一线+二线+补充），tf-cbt-emdr 是**一线证据边界**的聚焦。本卡涵盖瑜伽/神经反馈/创意治疗，tf-cbt-emdr 聚焦 TF-CBT/ET/EMDR 的证据等级与文化适配。
  - 与 `body-memory`：本卡回答"选哪条康复路径"，body-memory 回答"为什么身体需要被纳入康复"。
  - 与 `prevention-five`：本卡是**治疗期**路径选择，prevention-five 是**创伤后黄金期**预防。

## E — Execution（可执行步骤）
**输入契约**：用户询问创伤治疗选择/比较疗法/讨论某种疗法是否合适。
1. **判断阶段**：当前是否在急性危机/高不稳定期？是 → 先稳定化（情绪调节+安全），不上暴露/EMDR。完成标准：能说出当前稳定化等级。
2. **介绍一线选项**：TF-CBT（含暴露）与 EMDR 疗效相当（L00387），按可及性与偏好选择。完成标准：用户理解两种一线疗法大致等效。
3. **介绍辅助路径**：正念/冥想（二线）、瑜伽/躯体感觉/创意治疗（补充/adjunct），不替代一线。完成标准：用户区分"一线主治疗"与"辅助补充"。
4. **文化/躯体适配**：高躯体化或非西方背景者先教放松/冥想再暴露（L00415）。完成标准：用户理解顺序原则。
5. **转介**：建议与持牌创伤治疗师讨论，不自行选择疗法。完成标准：用户知道这是需要专业指导的决策。
**输出契约**：一张"稳定化→一线加工→辅助补充"的分层路径图 + 文化适配提示 + 转介建议。

## B — Boundary（边界与红线）
- **不自行开治疗方案**：本卡是疗法选择的循证地图，不替代持牌治疗师的个体化治疗规划。
- **不把补充疗法神化**：瑜伽/针灸/艺术治疗是 adjunct，不是"治愈创伤的终极方案"；证据有限时如实说明。
- **不跳过稳定化直接暴露**：在急性危机/高不稳定/自伤风险下直接上暴露或 EMDR 可能恶化症状。
- **EMDR 眼动非魔法**：眼动成分本身未被证实为必要（L00408），不宣传"眼动特效"。
- **不否定谈话疗法**：语言叙事对有能力言说的创伤仍然有效；躯体取向是补充而非取代。
- **安全红线**：伴自伤/自杀/解离失控/物质中毒时，一切疗法讨论让位于危机安全计划；不替代精神科诊断与药物治疗。
