# 完成被阻断的本能动作（Biological Completion / 完成未完成的动作）

## I — Interpretation
战/逃是整套有强烈"完成驱力"的动作程序：肌肉绷紧、呼吸、姿势都为某个具体动作（跑、挡、推、转方向盘、缩成一团保护自己）准备好了。当时如果动作被阻止、没做成，这套程序收不到"我做完了"的本体感觉反馈，于是神经回路一直挂着"待办"，年复一年准备着同一个动作——这就是程序记忆式的侵入。SE 的核心手法是：在安全关系里，通过想象和**细微的、放慢的身体动作**，把当年没做完的那个动作"补做完"。身体一旦收到"动作完成了"的反馈，交感才能撤防，副交感回弹，能量被释放。注意：这不是在重新暴露于创伤记忆，也不是压抑，而是在体感层把那段中断的动作续完。

## A1 — Application Example
Simon 车祸个案（LE03 L0013–L0014）：治疗师说"感觉你自己去转方向盘！放慢！让你现在去做你当时做不到的事"；Simon 极缓慢地做出转方向盘的动作、完成、大叹一口气，说"我做到了，我自由了，肩膀轻了"。另一例 Nancy（LE02 L0001–L0003）：在老虎意象中"跑、爬上岩石逃"，约30分钟颤抖后松弛。共同结构：**把当年想做而不能做的动作，在安全中做完**。

## A2 — Future Trigger
- 场景：对方卡在某个反复出现的躯体/动作冲动——"当时我想推开/想跑/想喊却动不了"；或做了很多谈疗法仍卡在同一个身体紧。
- 语言信号："当时我好想推开他 / I wanted to push him away"；"我明明该逃却钉在原地 / I should have run but I was stuck"；"身体总在绷着一个劲儿 / my body keeps tensing up like it wants to do something"。
- 与相邻能力区分：
  - 与 `animal-release-cycle` 分工：那张讲"系统本会恢复"的原理；本卡讲"具体怎么帮动作走完"。
  - 与 `pendulation`/`titration` 分工：那两张是安全进出的节奏；本卡是节奏之内要**完成的那个动作本身**。
  - 与 In an Unspoken Voice 的关系：本卡是 Levine 1997 的**操作核心**；IUSV 给它补上神经/多迷走理论解释（为何背侧迷走关机时不能硬推动作）。

## E — Execution
1. 在已资源化、已滴定的状态下，问："此刻你的身体想做个什么动作？推？跑？缩起来？护住哪里？"完成标准：识别出一个具体动作冲动（不是故事）。
2. 放慢它："慢慢来，用你需要的全部时间，让肩膀/手臂去做它想做的。"完成标准：动作在安全中被实际/想象地做出，而非被忍住。
3. 完成后停住，观察身体反馈：呼吸、叹息、松弛、发热。完成标准：出现释放信号（见 discharge-signs）或明确的"做完了"感。
4. 确认"现在的你"完成了，而不是当年那个无助的人。完成标准：对方报告肩膀/胸口轻了、能呼吸。
- 输入：一个被识别出的、当年被阻断的动作冲动。输出：一次体感层的动作完成 + 随之而来的松弛反馈。
- 红线：动作**放慢、不强迫**；若对方说"我要失控了"或解离，立刻回资源；这不是发泄式乱摔打。

## B — Boundary
- 反场景：把"完成动作"做成情绪宣泄/打枕头发泄——SE 强调的是**放慢、觉察、与完成反馈结合**，不是高强度宣泄。
- 失败模式：在没有资源/滴定的情况下硬推"去转那个方向盘"，可能把系统推到交感+背侧迷走共激活（LE03 L0004），造成淹没。
- 程序记忆红线：躯体动作冲动是通达通道，但**不等于**必须回忆完整事件；想不起情节也能做。
- 作者/证据盲点：LE03 L0018–L0019 的"允许完成逃脱则恐惧消退"来自大鼠；人身上为个案与初步证据（LE04）。
- 总红线：这是 SE 治疗的核心技术，通常需受训治疗师引导；自我练习只做轻微、可回退的版本，不替代专业创伤治疗。
