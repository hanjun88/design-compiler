# GLOSSARY.md — Waking the Tiger 全书共享术语

| 术语 | 英文 | 简明定义 | 证据 |
|---|---|---|---|
| 躯体体验疗法 | Somatic Experiencing (SE) | Levine 创立的身体取向创伤疗法，自下而上，引导注意内感受/本体感觉，完成被阻断的本能防御反应 | LE03 L0001 |
| 摆动 | Pendulation | 躯体感觉在充电/激活与放电/安心间的有节奏往返 | LE02 L0019; LE03 L0008 |
| 滴定 | Titration | 借化学滴定比喻，一滴一滴引入创伤材料以防淹没 | LE03 L0009 |
| 资源建立 | Resourcing | 先连接安全/力量/舒适的正性躯体标记，作为可退回的资源库 | LE02 L0017 |
| 放电/释放 | Discharge | 通过颤抖、打哈欠、流泪、发热、长叹释放过度交感唤醒 | LE03 L0011 |
| 生物完成 | Biological completion | 在安全中完成当年被阻断的本能防御动作，通知自主神经"动作已完成" | LE03 L0015 |
| 僵住/不动反应 | Freeze / Immobility | 战逃不可行时的第三生存反应，装死，本应短暂 | LE01 L0008 |
| 体感/体感觉察 | Felt sense | 对身体内部信号的直接觉察（内感受） | LE03 L0006 |
| 过度唤醒 | Hyperarousal | 神经系统"油门"，持续高亢警觉 | LE02 L0013 |
| 收缩 | Constriction | 应激时收窄知觉、改变呼吸姿势以聚焦威胁 | LE02 L0011 |
| 解离 | Dissociation | 与自身/时间/空间断连的连续谱 | LE02 L0014 |
| 紧张性不动 | Tonic immobility | 极端压力下交感与副交感同时亢进的僵死/晕厥样状态 | LE03 L0004 |
| 程序记忆 | Procedural memory | 身体"怎么做"的记忆，经体感而非叙述通达 | LE03 L0020 |
| 核心反应网络 | CRN | 皮层下自主神经/边缘/运动/唤醒构成的动态系统 | LE03 摘要 |
| 容忍窗 | Window of tolerance | 唤醒的可承受区间（与 Complex PTSD 最优唤醒窗呼应） | 跨书 |
