# 权力斗争阶段：热恋结束不是关系坏了，是开始了

## I — Interpretation
Hendrix 把关系分成几个阶段：
1. **浪漫期/蜜月**：imago 投影阶段。你把理想父母的形象投在对方身上，觉得"终于找到了对的人"。
2. **权力斗争期**：蜜月幻觉破灭。对方开始不符合你的 imago 期待，你发现他不是来"救你"的，他是另一个普通人。冲突爆发：你为什么不按我需要的方式爱我？双方都想赢、想改造对方、想证明自己是对的。
3. **意识期/重承诺期**：你意识到伴侣不是来满足你所有需求的神，而是一个和你一样有伤口的人。从"你要改"转向"我们一起理解"。
4. **创造期/共同使命**：把关系从"满足我"变成"我们一起创造什么"。

**关键洞察**：权力斗争不是关系坏了，是关系**开始了**。大多数关系死在这个阶段——因为双方以为斗争意味着"选错了人"，于是换人，把同一个 imago 剧本在下一个关系重演。Hendrix 的立场是：**权力斗争里的每一次冲突，都是童年未完成事件的重演，也是一次被治愈的机会**。前提是你知道你在哪一阶段。

## A1 — Application Example
合成演练：结婚第三年，妻子想离婚："他婚前会陪我说话，婚后就只会看球。" 传统解读：他变了，选错了人。Imago 解读：
- 浪漫期：她把"会陪我说话的理想父亲"投在他身上。
- 权力斗争期：他不可能一直维持投影状态。她失望的不是他变了，是**投影脱落了**。
- 治疗转向：从"你为什么不像以前那样"转向"我小时候最缺的就是有人听我说话。你愿意试试用一种新的方式听我吗？"——这才是 imago 工作。

## A2 — Future Trigger
**场景**：你刚进入或正在经历"怎么变成这样了"的阶段；你反复想"是不是选错人了"；你们为同一件事吵了很多年；你觉得关系从浪漫变成了战场。
**语言信号**：
- "我们刚在一起的时候不是这样的" / "It wasn't like this when we started"
- "我们总是吵同一件事" / "We fight about the same thing"
- "我是不是选错人了" / "Did I marry the wrong person"
- 你想过换人会不会更好。
**与相邻能力区分**：imago-match-decode 解释为什么选这个人；本卡解释**热恋后会发生什么、你在哪一站**。

## E — Execution
1. **定位阶段**（5分钟）：你们现在最像哪一段？浪漫/权力斗争/意识/创造。写一句话。完成标准：阶段名 + 一句证据。
2. **识别重复主题**（10分钟）：写下你们最近半年吵得最多的 1-3 个主题。完成标准：1-3 个主题。
3. **投影检查**（10分钟）：这些主题里，有多少和你小时候的某个未满足需求是同构的？（比如"他不听我"= 小时候"我妈不听我"）完成标准：每主题一条童年映射。
4. **不换人先换剧本**：写下一句替代"他选错了"的话："这是我 imago 剧本的第___次重演。"完成标准：一句。
5. **转向意识期**：承诺在下次冲突时，用 imago-dialogue（mirror/validate/empathize）替代争吵。完成标准：约定一个开始日期。

## B — Boundary
- 反场景：权力斗争里如果出现身体暴力、持续威胁、严重控制，那不是"正常阶段"，那是安全问题。先安全。
- 失败模式：把"权力斗争是正常的"用来忍受不可接受的行为。正常阶段也需要边界。
- 不是所有冲突都要拖到"意识期"才解决——日常生活的实际问题可以当场解决，只有**反复出现、跨年份、和童年同构**的冲突才是 imago 工作的对象。
- 不要给伴侣做"阶段诊断"——这是你自己的觉察工具。
- 证据基础：Imago 阶段模型在临床实践中广泛使用，但阶段划分的实证验证有限。
