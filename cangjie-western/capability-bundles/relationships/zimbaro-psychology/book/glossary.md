# GLOSSARY — zimbaro-psychology

| 术语 | 英文 | 简释 |
|---|---|---|
| 认知失调 | Cognitive dissonance | 两个不一致认知引发的负性情绪驱动状态；人会被动机驱动去恢复"一致"。 |
| 降减策略 | Dissonance reduction | 恢复一致的方法；分回避型（淡化/逃避/合理化）和投入型（真改态度/行为）。 |
| 努力辩护 | Effort justification | 投入越多越要证明值得（Festinger 入组实验）。 |
| 基本归因错误 | Fundamental Attribution Error (FAE) | 把他人行为过度归因为人格，低估情境；又称 correspondence bias。 |
| 行动者-观察者不对称 | Actor-observer asymmetry | 对自己用情境，对他人用人格。 |
| 两阶段归因模型 | Two-stage attribution | 自动特质锚定 → 费力情境校正；认知资源不足时第二步跳过。 |
| 确认偏误 | Confirmation bias | 搜索/解释/记忆三通道都偏向支持已有信念；Wason 1960。 |
| 达尔文黄金法则 | Darwin's golden rule | 主动记录反证，因为大脑会自动删除反证。 |
| 服从权威 | Obedience to authority | Milgram 范式下普通人按权威指令升级伤害行为。 |
| 责任扩散 | Diffusion of responsibility | 当自己只是"中间人/角色"，道德判断外包给系统。 |
| 接近性/亲密度 | Proximity/Intimacy | 受害者越近、越亲，服从率越低（Meta-Milgram）。 |
| 精细加工可能性模型 | Elaboration Likelihood Model (ELM) | 中央路径（按论据质量）/ 边缘路径（按来源、语气等线索）。 |
| 能力/动机 | Ability/Motivation | 决定走哪条路径的两个变量。 |
| 睡眠者效应 | Sleeper effect | 来源折扣线索衰减快于论据，延迟后说服反而上升。 |
| 认知吝啬鬼 | Cognitive miser | 人在社交判断中省能的默认特征。 |
