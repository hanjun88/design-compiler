# 确认偏误：主动找"反证"，而不是只找"证据"

## R — Reading
来源 `raw/legal_open/04_confirmation_bias.txt`（PMC11495861, eNeuro 2024, CC BY）
- L00005–L00010: Wason 1960 "2,4,6" 实验：23/29 学生只提出支持自己假设的三元组，从不尝试违反假设的例子，所以发现不了真正规则。
- L00012–L00016: Rosenthal 自我实现预言；Tuyttens 猪视频实验（d=0.62）：人"看到"自己预期的东西。
- L00040–L00044: Darwin 黄金法则："每当出现与我总体结论相反的新事实/观察/想法，立刻做记录；经验告诉我，这类事实比有利的事实更容易从记忆中溜走。"

## I — Interpretation
确认偏误是三通道同时漏风：(1) **搜索**——只问能证实自己的问题；(2) **解释**——对模糊信息按自己预期解读；(3) **记忆**——只记住支持性的例子。在关系里，一旦你判定"他不在乎我"，你会：记得他三次忘记你说的事，自动原谅他十次为你做事；他发消息慢了=冷漠，你自己忙没回=正常；朋友问起，你只举支持例子。Wason 实验的核心教训：**要证明一个假设，光找支持它的例子是不够的——你必须主动去找能推翻它的例子**。Darwin 的方法是结构性的：把反证写下来，因为大脑会自动删除它。

## A1 — Application Example
合成演练：你怀疑"他已经不爱我了"。按确认偏误运行的一天：他没主动发消息（证据1），他忘了你们的餐厅预订（证据2），他周末想自己打游戏（证据3）。你把这三件事发给闺蜜，闺蜜说"分"。达尔文式的反证清单应该包括：他上周半夜陪你去急诊（你自动归为"朋友都该这样"）；他记得你过敏的食材（归为"小事"）；他连续三个月加班还在周末给你修车（归为"本来就该做"）。**反证不是要你否定痛苦，是要你别让偏见替你做判决。**

## A2 — Future Trigger
**场景**：你已经形成了一个关于伴侣的结论（好或坏），并开始"收集"支持这个结论的日常证据；你发现自己只和会同意你的朋友聊；你对新信息的第一反应是"看吧，果然"。
**语言信号**：
- "你看，我早就说过吧" / "See, I told you"
- "他最近怎么老是…"（只列最近的）/ "He's been so ___ lately"
- 朋友提出反面例子时，你立刻反驳（"那是…"）/ "Yeah but…"
- 你翻聊天记录/朋友圈只找特定内容。
**与相邻能力区分**：基本归因卡处理"对行为的人格化解释"；本卡处理"证据只往一个方向流"。归因错了可以改，证据流被污染了，改什么都没用。

## E — Execution
1. **写下你的假设**（1分钟）：用一句完整的话写出你对伴侣/关系的判断。模板："我认为他/我们___。"完成标准：一句话，不含模糊词。
2. **达尔文反证清单**（5分钟）：写下**至少3件与该假设矛盾的具体事件**（时间、行为、当时情境）。硬性规则：每件必须具体到"什么时候他做了什么"，不许用"有时"。完成标准：≥3条带时间地点的反例。
3. **重新表述问题**（2分钟）：把"他是不是X"换成"什么证据会改变我的想法？如果找不到这样的证据，我的判断就不可证伪，也就是信仰而不是结论。"完成标准：写下一句"如果___发生，我会改变看法"。
4. **找一个你知道会反对你的人**聊一次，只听不反驳。完成标准：真的聊了，并记下对方至少一个论点。

## B — Boundary
- 反场景：涉及安全、虐待、成瘾、反复背叛时，"找反证"不能用来拖延安全决策。安全问题的"反证"应该是**行为改变**（持续数月、可验证），不是你的善意解读。
- 失败模式：把反证清单变成"自我说服"——如果你列出反例后仍强烈怀疑，那个怀疑本身是数据，不要硬压。
- 情绪不是证据，但被忽略的反例也不是中立。目标是对称，不是偏向另一边。
- 本卡不要求你"积极思考"，只要求你**证据对称**。
