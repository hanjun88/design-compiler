# GLOSSARY — Attached

| 术语 | 中文 | 定义 |
|---|---|---|
| Attachment anxiety | 依恋焦虑 | 对被抛弃/拒绝/不被爱的恐惧维度 |
| Attachment avoidance | 依恋回避 | 对亲密/依赖/情绪表达的回避维度 |
| Hyperactivation | 过度激活 | 焦虑型策略：放大问题与情绪以获得回应 |
| Deactivation | 去激活 | 回避型策略：最小化问题与情绪以维持距离 |
| Internal Working Model (IWM) | 内部工作模型 | Bowlby 提出的自我模型+他人模型 |
| Protest behavior | 抗议行为 | 焦虑型为逼对方回应而做的情绪升级动作 |
| Secure base | 安全基地 | 可依赖的依恋对象带来的探索底气 |
| Safe haven | 安全港 | 压力时可退回的依恋对象 |
| Earned security | 获得性安全 | 非原生安全型但通过关系经验发展出的安全 |
| ECR-R | 经验关系量表-修订版 | Brennan 两维测量工具 |
| Relationship mindfulness (RM) | 关系正念 | 有意识、非评判地关注当下关系互动 |
| Bid | 邀请/投标 | 伴侣发起的连接尝试 |
