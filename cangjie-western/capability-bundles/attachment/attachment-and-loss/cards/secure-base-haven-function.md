# 安全基地 × 安全港：关系支持质量评估

## R — Reading
> "No concept within the attachment framework is more central to developmental psychiatry than that of the secure base." (Bowlby 1988)
> "The secure base phenomenon contains two intertwined components: a secure base from which a child can explore and a haven of safety to which the child can return in times of distress."
> — PMC4085672:9,11 (raw/legal_open/pmc4085672_attachment_theory_review.md)

## I — Interpretation
一段好的依恋关系同时承担两个功能：
- **安全港 (haven of safety)**：你遇险、疲惫、害怕时，回去能被接住、被安抚。
- **安全基地 (secure base)**：你被安抚后，敢从这个人身边出发去探索世界、发展能力。
婴儿问的核心问题是："**当我激活依恋系统、需要亲近时，这个人会怎么做？**"
答案若多数时候是"可接近、可回应、可依靠" → 形成安全基地脚本；若不可得/被拒/惊吓 → 形成不安全脚本。
注意：Bowlby 强调，关键不是"全天都在"，而是**"需要时（尤其疲惫/害怕时）可敏感回应"**。

## A1 — Application Example
合成演练（评估一段成人支持性关系）：
- 安全港项：我难过/生病/害怕时，对方是否可接近、不嘲笑、能帮我平静下来？
- 安全基地项：从这段关系出发，我是否更敢尝试新工作/新关系/新探索，还是反而更萎缩？
- 健康关系：两个项都高。
- 红灯关系：两个项都低，或"看似亲密但你越来越不敢探索"（控制型）。
- 完成标准：能用这两个轴评估关系，而不只看"他对我好不好"。

## A2 — Future Trigger
- 场景：
  1. 用户想评估一段关系（伴侣/朋友/治疗/家庭）是否"健康的支持"
  2. 用户问"为什么我在这段关系里反而越来越没自信"
  3. 想理解什么是"安全的关系"
- 语言信号：secure base、safe haven、安全基地、安全港、"他能不能在我脆弱时接住我"、"这段关系让我更敢还是更怕"
- 与相邻区分：
  - attachment-system-activation 看单次激活
  - abcd-pattern 看个人策略
  - 本卡看**关系本身的双功能质量**

## E — Execution
输入契约：一段具体关系的近期互动样本（至少 1 次对方脆弱时刻 + 1 次自己探索时刻）。
1. 安全港轴打分（0–2）：需要时对方是否可接近、回应、帮你平复？
2. 安全基地轴打分（0–2）：从这段关系出发，你是否更敢探索/成长，还是更退缩/依附？
3. 模式判断：
   - 2/2 → 健康安全基地
   - 高安全港 + 低基地 → 可能过度依附/共生
   - 低安全港 + 高基地 → 表面独立但无人可归
   - 低/低 → 不支持
4. 输出："这段关系在安全港上是__，在安全基地上是__；若长期低安全港，你的 IWM 会被反复强化为'需要时无人'。"
5. 不评判、不劝分；仅提供评估透镜。

## B — Boundary
- 反场景：不要用这把尺子要求所有关系（同事/熟人不需要安全基地功能）。
- 失败模式：
  - 把"对方偶尔没回应"就判为不安全；Bowlby 说的是"多数时候"，不是完美照料。
  - 用"安全基地"美化控制型关系（控制会让你不敢探索，基地轴必然低）。
- 文化差异：安全/独立的表达受文化塑造。
- **安全红线**：若评估发现关系中有暴力、持续恐吓、让你越来越害怕/萎缩——这不是"依恋质量低"，而是人身安全问题，优先求助专业资源。
- 跨书链接：治疗师作为安全基地的临床操作见 Wallin《Attachment in Psychotherapy》。
