# PACT 四风格: Anchor / Wave / Island / Mixed

## R — Reading
来源 `legal_open/pact_styles_numbered.txt`（PACT 培训师公开文章，Cordoba Couples Therapy）
- L00004: "PACT describes four distinct orientations through evocative names: the **Anchor, the Wave, the Island, and the Mixed Style**. Each captures a different way of seeking safety within a relationship… The Anchor represents the secure attachment orientation… The Wave describes the anxious-ambivalent attachment orientation… The Island describes the avoidant attachment orientation… The Mixed Style, corresponding to the disorganized or fearful-avoidant attachment pattern…"

## I — Interpretation
PACT 不直接用"安全/焦虑/回避/混乱"四个学术标签，而是用 evocative 命名：
- **Anchor 锚** = 安全型：情绪稳定，冲突后自然修复；
- **Wave 浪** = 焦虑型：对距离高度警觉，用升级/抗议获得回应；
- **Island 岛** = 回避型：压力下抽离，自给自足，情感需求隐藏；
- **Mixed 混合** = 混乱型：同时渴望又恐惧亲近，推拉。

PACT 的关键转换：风格不是宿命，是神经系统在压力下的默认操作模式。目标不是"变成 Anchor"，是双方共同构建 secure functioning——互为安全基地，无论各自历史如何。

## A1 — Application Example
**合成演练**（基于 PACT 四风格公开描述）：
1. 自识别压力下的默认反应：稳定 (Anchor) / 升级 (Wave) / 抽离 (Island) / 推拉 (Mixed)；
2. 识别伴侣默认反应；
3. 标注互动组合（Wave×Island 最常见）；
4. 不评判："他不是冷漠，是 Island 在过载；她不是作，是 Wave 在求回应"；
5. 设计 co-regulation 协议（见 secure-island-protocol）。

## A2 — Future Trigger
- 场景："我们到底是谁和谁" / "What are we, really?"
- 语言信号："我一吵就想消失"（Island）；"我一吵就停不下来"（Wave）
- NVC 提示："PACT 不说你是焦虑型/回避型，说你是 Wave 还是 Island。Wave 一感到距离就升级，Island 一感到情绪就抽离。你们俩不是在互相伤害，是两套神经系统在压力下各自按默认程序跑。下一步不是改性格，是写一份'过载时怎么办'的双人协议。"
- 与相邻能力区分：Attached 的 style-map 是两维坐标；本卡是 PACT 风格命名 + 互动组合识别。

## E — Execution
| 步骤 | 输入 | 完成标准 |
|---|---|---|
| 1. 自识别 | 压力下默认 | 命名 1 个风格 |
| 2. 伴侣识别 | 观察 | 命名伴侣风格 |
| 3. 组合标注 | 双方 | 写出组合（如 Wave×Island） |
| 4. 去道德化 | 上述组合 | 把"他冷漠/她作"翻译为神经系统默认程序 |
| 5. co-reg 协议 | 下周 | 约定过载时的双人动作 |

输入：一段"我们一吵架就…"。输出：双方风格 + 组合 + 去道德化翻译 + co-reg 协议草稿。

## B — Boundary
- 反场景：把 PACT 风格当判决书。
- 失败模式：用"我是 Island"合理化永不回归。
- 作者盲点：PACT 风格混合常见，不要硬贴一个标签。
- **安全红线**：风格解释不消除行为责任；跟踪/控制/暴力不是 Island/Wave 风格，转安全评估。
