# 决策规则速查 — Attachment and Loss (Vols.1-3)

| 能力 | 一句话规则 |
|---|---|
| 依恋系统激活—去激活识别 | 威胁/分离时朝向某人的亲近寻求=依恋系统激活，要联结确认而非问题解决 |
| 内部工作模型解释关系重复 | 早期照料编译成"自我是否值得被回应×他人是否可靠"的自动脚本，成年后自证预言 |
| ABCD 依恋四模式识别 | 安全/回避(去激活)/矛盾(过度激活)/失序(无组织) 四策略，按压力下行为判倾向 |
| 儿童分离三阶段 protest/despair/detachment | 儿童分离经抗议→绝望→疏离；突然不哭了常是防御而非恢复 |
| 成人哀悼四阶段定位 | 麻木-震惊/思念-搜寻/失序-绝望/重组；重叠可往返，非线性必经 |
| 正常哀悼 vs 复杂性哀伤 区分与转介 | 时长≥6-12月+持续思念无法接受+功能损害+自杀风险=转介，不自助安慰 |
| 安全基地×安全港 关系支持质量评估 | 一段支持性关系=遇险能被接住(安全港)+被安抚后敢探索(安全基地) |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
