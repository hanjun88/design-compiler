# ABCD 依恋四模式识别

## R — Reading
> "Four attachment behavioural patterns have been defined in young children: secure; insecure avoidant; insecure resistant (also called ambivalent); disorganised… The insecure avoidant and resistant patterns… are organised attachment patterns… In contrast, children who are classified as disorganised appear to lack an organised strategy for achieving closeness."
> — NICE NBK356196:3,4 (raw/legal_open/nbk356196_attachment_patterns.md)

## I — Interpretation
Ainsworth 陌生情境 (SSP) 在分离-重聚压力下观察婴儿策略，归纳为四类（后 Main 加入 D 类）：
- **B 安全**：遇险能被安慰，能把照料者当基地出去探索；重聚时主动接触、容易平静。
- **A 回避 (avoidant)**：**去激活**——自己压下求助信号，表面独立；重聚时冷淡、回避接触。
- **C 矛盾/反抗 (resistant/ambivalent)**：**过度激活**——放大焦虑，分离后极度痛苦又愤怒，重聚时既想靠近又挣扎，难安抚。
- **D 失序 (disorganized)**：**没有组织策略**——走近却转头、僵住、茫然、恐惧。
关键：A/C 是"组织化的策略"（为了在预期照料下保住亲近而采取的生存方案）；D 是策略崩溃。
成人版对应：安全 / 轻视型 dismissing（去激活）/ 先占型 preoccupied（过度激活）/ 未解决 unresolved。

## A1 — Application Example
合成演练：
- A 画像：伴侣加班未回消息，一方说"我没事，我自己能忙"，但那晚失眠、第二天冷淡——去激活策略（表面关闭，身体在反应）。
- C 画像：伴侣晚归一小时，一方连环 call、一见面就哭着质问"你是不是不在乎我"，安抚无效——过度激活。
- D 信号：面对亲近时出现矛盾动作（想抱又推开、僵住、恍惚），或关系中既极度黏人又突然暴怒——需警惕未解决创伤。
- 完成标准：能判断"这个人在过度激活还是去激活"，而不是只贴"焦虑型/回避型"标签。

## E — Execution
输入契约：用户在压力/分离/重聚情境下的典型反应模式描述。
1. 问三个情境题：
   (a) 你难过时，倾向找人安抚还是自己扛？
   (b) 对方疏远时，你倾向追上去确认还是装作无所谓？
   (c) 你描述童年关系时，叙事是连贯平衡还是混乱/矛盾？
2. 按信号对照：
   - 找安抚+重聚快平静 → 倾向安全
   - 自己扛+回避接触 → 倾向去激活 (A/dismissing)
   - 放大焦虑+难安抚+愤怒 → 倾向过度激活 (C/preoccupied)
   - 矛盾动作、僵住、叙事情感与内容不一致 → 警惕 D/unresolved
3. 输出：**假设**而非判决；说明这是倾向，不是终身标签。
4. 判停：若信号指向 D/unresolved，转 unresolved-trauma-referral（Wallin）/ complicated-grief-differential 进一步评估，不强行归类。

## B — Boundary
- 反场景：不要在第一次对话就判型；NICE 指出临床医生凭直觉判型准确度低于 AAI 等工具。
- 失败模式：
  - 把"回避"当冷漠/不爱，把"焦虑"当作/作闹——两者都是生存策略，不是道德缺陷。
  - 用 disorganized 反推虐待（NICE 明确禁止：不能从分类反推虐待史）。
- 依恋模式 ≠ 精神障碍 ≠ 虐待指标；随关系改变而可变。
- **安全红线**：D/unresolved 信号（解离、暴怒、对亲近的恐惧矛盾）常与未解决创伤相关，不要自助深挖，建议专业评估。
