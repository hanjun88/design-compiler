# EFT 情绪罗盘核心框架

## I — Interpretation
EFT 由 Sue Johnson 在 1980 年代基于依恋科学发展，核心命题：情绪不是关系噪音，是罗盘——它指向未被满足的依恋需求（被看见、被回应、可依靠）。EFT 不追求快速修复，而是触及问题核心：把"情绪是干扰"改为"情绪是数据"。治疗三阶段：①去 escalate（识别负向循环）；②重构（分享依恋恐惧与渴望）；③巩固。终点是安全纽带。

## A1 — Application Example
**合成演练**（基于 ICEEFT 官网公开内容）：
1. 识别"情绪无用论"（忍一忍/理性至上）；
2. 重构：情绪是罗盘（指向需求/威胁）；
3. 定位当下情绪背后的依恋需求；
4. 用情绪语言而非评判语言表达。

## A2 — Future Trigger
- 场景："吵架的时候我只想冷静，情绪有什么用？" / "When we fight I just want to be rational."
- 语言信号："别闹情绪" / "讲道理" / "冷静点"
- NVC 提示："情绪不是来捣乱的，它是你的罗盘——愤怒在说'我的边界被碰了'，恐惧在说'我怕失去你'。下次吵架时，把'你总是这样'换成'我现在很怕，因为我需要确认我们还在同一艘船上'。"
- 与相邻能力区分：`demand-withdraw` 是具体循环识别；本卡是总原则（情绪=罗盘）。

## E — Execution
| 步骤 | 输入 | 完成标准 |
|---|---|---|
| 1. 情绪标签 | 当下情绪 | 命名 1 个（愤怒/恐惧/悲伤/羞耻） |
| 2. 需求定位 | 上述情绪 | 1 句"它在告诉我我需要…" |
| 3. 罗盘句 | 上述需求 | 1 句以"我"开头的需求表达 |
| 4. 替换评判 | 常用指责句 | 改写为罗盘句 |

输入：一段"我又失控了"的复盘。输出：情绪标签 + 需求句 + 罗盘表达。

## B — Boundary
- 反场景：把一切情绪正当化为行为理由。
- 失败模式：在施虐/控制语境中要求"表达脆弱"（可能被利用）。
- 作者盲点：本书对抑郁/焦虑障碍的医学共病讨论少。
- **安全红线**：EFT 是治疗框架，不替代精神科诊断或危机干预；若关系中有暴力，停止脆弱表达练习，转安全计划。
