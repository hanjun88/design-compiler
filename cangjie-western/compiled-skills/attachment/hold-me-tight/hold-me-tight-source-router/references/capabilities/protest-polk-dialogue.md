# Protest-Polka 指责-防御对话

## R — Reading
来源 `legal_open/07_what_is_eft_public.txt`（ICEEFT 官网公开内容）
- L00029–L00053: EFT Stage One De-escalation 中，治疗师帮助伴侣觉察负向循环，把"被抛弃/被拒绝"看作共同敌人；焦虑方的指责 (protest) 与另一方的防御 (polka 舞步式躲闪) 形成第二轮魔鬼对话。

## I — Interpretation
Protest-Polka 是第二套魔鬼对话：一方用指责、翻旧账、人身攻击来"抗议"对方的疏远；另一方不退缩，但跳舞式躲闪——讲道理、反指责、列证据、证明"不是我的错"。表面上两人都在说话，实际上谁也没听见谁。指责方要的是情感回应，防御方给的是逻辑辩论。结果：指责方越攻击越确信"他根本不在乎"，防御方越辩论越确信"她不可理喻"。这不是沟通问题，是两套依恋系统在错误频道上喊话。

## A1 — Application Example
**合成演练**（基于 ICEEFT 去 escalate 阶段框架）：
1. 回放吵架；
2. 标注：谁在"抗议"（攻击/翻旧账/人身）？谁在"躲闪"（讲道理/反指责）？
3. 翻译：抗议方表面是"你从不做家务"，底下是"我需要你看见我"；
4. 翻译：防御方表面是"我做了啊你看清单"，底下是"我怕你觉得我不够好"；
5. 双方把表面句换成底下句。

## A2 — Future Trigger
- 场景："我们一吵架就翻旧账" / "We fight and never resolve anything."
- 语言信号："你从来…" / "你总是…"（抗议方）；"但是…" / "我已经…"（躲闪方）
- NVC 提示："你那句'你从不做家务'，底下其实是'我一个人撑着，我需要你看见'。他回的'我已经做了啊'，底下其实是'我怕你觉得我不够好'。下次试试把表面句翻译成底下句——不是翻旧账，是把旧账背后的害怕说出来。"
- 与相邻能力区分：`demand-withdraw` 是追-逃；本卡是追-挡（双方都在场但频道不同）。

## E — Execution
| 步骤 | 输入 | 完成标准 |
|---|---|---|
| 1. 表面句 | 吵架中双方各 1 句 | 原样写下 |
| 2. 底部翻译 | 表面句 | 各写 1 句依恋需求 |
| 3. 频道检查 | 双方 | 标注"我在要情感，他在给逻辑" |
| 4. 替换表达 | 下次吵架 | 用底部句替换表面句 |

输入：一段"我们越吵越远"的复盘。输出：表面句 + 底部翻译 + 替换表达。

## B — Boundary
- 反场景：把所有指责都正当化为"依恋需求"。
- 失败模式：用"我在表达依恋需求"合理化人身攻击。
- 作者盲点：Protest-Polka 在认知扭曲/人格障碍语境下需要不同框架。
- **安全红线**：若指责升级为侮辱、跟踪、威胁，停止依恋翻译，转安全评估。
