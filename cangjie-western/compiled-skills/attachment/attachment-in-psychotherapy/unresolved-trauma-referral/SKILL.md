# 未解决创伤/丧失识别与转介红线

## R — Reading
> "Unresolved loss and trauma leads to extreme emotion dysregulation. These individuals have learned to regulate attachment distress through approach and avoidance. When these forces are strongest, it can result in a breakdown in cognition and affect resulting in uncontrollable rage and dissociation. These individuals need to resolve previous traumas and losses…"
> — Sonkin:12
>
> "Neither the behaviour… nor a classification of disorganised attachment in the SSP, can be used in any valid way to assess a child for maltreatment."
> — NICE NBK356196:10

## I — Interpretation
未解决的创伤/丧失在依恋框架里表现为**失序 (disorganized/unresolved)**：approach 与 avoidance 同时被激活，个体无法用任何一种组织化策略应对，于是：
- 面对亲近时出现矛盾（想靠近又僵住/恐惧）
- 情绪调节崩溃：极端暴怒、解离、闪回
- 叙事情感与内容不一致（AAI 中谈到丧失/创伤时推理中断、话语迷乱）
- 常伴：反复自伤、自杀念头、关系中极端的 push-pull
这些信号说明来访者**当前的心智化与情绪调节能力不足以支撑普通的依恋探索**；在未稳定化前做童年诠释、情绪宣泄，可能加剧解离或崩溃。
正确动作：先创伤处理/稳定化，必要时精神科评估；自助语境下不深挖。

## A1 — Application Example
合成演练：
- 信号清单命中 ≥2：
  (a) 谈到早年丧失/创伤时话语突然中断、神情恍惚（解离微表情）；
  (b) 关系中同时极度黏人又突然暴怒/冷暴力；
  (c) 自伤、自杀念头、闪回；
  (d) 对亲近有恐惧式矛盾（想被爱又觉得靠近一定会被伤害）。
- 动作：不继续"理解你的依恋模式"，而是：
  1. 评估当下安全（自杀/自伤/暴力）；
  2. 建议寻求创伤取向的专业治疗（如 TF-CBT、EMDR、创伤聚焦心理治疗，由专业人员选择）；
  3. 不自助深挖记忆。
- 完成标准：能识别"这超出了依恋模式理解的范围"，果断转介。

## A2 — Future Trigger
- 场景：
  1. 用户描述解离、闪回、非现实感
  2. 用户在关系中出现无法解释的极端暴怒/恐惧
  3. 用户有自杀/自伤念头
  4. 心理学习者想区分"不安全依恋"和"需要创伤治疗"
- 语言信号：dissociation、解离、flashback、闪回、自伤、自杀、unresolved trauma、"我不知道自己怎么了"、uncontrollable rage、panic attack
- 与相邻区分：
  - adult-strategy-matching 处理组织化策略（preoccupied/dismissing）
  - 本卡处理**失序/崩溃**——转介，不干预
  - complicated-grief-differential（Bowlby）处理病理性哀伤

## E — Execution
输入契约：用户当前功能状态 + 上述信号清单。
1. 安全快筛（最高优先级）：
   - 有无自杀/自伤念头、计划、手段？
   - 当前关系中有无暴力/虐待威胁？
   - 有无急性精神病性症状？
   - 任一为是 → 立即建议紧急服务/危机热线/急诊，停止自助分析。
2. 创伤信号清单（≥2 项）：
   - 解离/闪回/非现实感
   - 叙事情感与内容断裂
   - 对亲近的恐惧式矛盾
   - 极端情绪调节崩溃（暴怒/瘫软）
   - 自伤/自杀史
3. 决策：
   - 命中 ≥2 项 → 明确建议寻求创伤取向的持证专业治疗；不推荐具体疗法，不指导自我暴露/宣泄。
   - 0–1 项 → 可继续依恋框架内的理解，但仍不替代治疗。
4. 输出：一句"你描述的 X 信号超出了自助依恋理解的范围，建议联系 [当地精神卫生/创伤治疗资源]；此刻若有自杀念头请立即拨打 [当地紧急/危机热线]。"

## B — Boundary
- 反场景：
  - 不要对未稳定化者做暴露式记忆挖掘、空椅、宣泄。
  - 不要把 disorganized 依恋分类当作虐待的证据（NICE 明确禁止反推）。
  - 不要把创伤症状浪漫化为"依恋风格"。
- 失败模式：
  - 用"这是你的依恋创伤"解释一切，延误精神科治疗（如双相、PTSD、解离障碍）。
  - 在聊天中提供创伤"治疗脚本"。
- **安全红线（最高优先级）**：
  - 本卡的唯一主动动作是**识别并转介**，不是治疗。
  - 自杀/自伤/家暴/急性精神病 → 立即紧急资源，不继续对话。
  - 不诊断 PTSD/解离障碍/复杂哀伤；由专业人员做。
  - 跨书：与 Bowlby 的 complicated-grief-differential 互补，两者命中红线都转介。
