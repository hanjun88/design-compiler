# 决策规则速查 — Attached: The New Science of Adult Attachment

| 能力 | 一句话规则 |
|---|---|
| 焦虑×回避双维度地图 | 成人依恋用焦虑(怕失去)与回避(怕亲密)两个连续维度测绘，而非安全/焦虑/回避三类标签。 |
| 内部工作模型(IWM)识别 | 你如何看待自己(是否值得被爱)与重要他人(是否可依赖)的地图，由早期经验绘制，持续指导亲密关系。 |
| 焦虑型激活策略(Hyperactivation/Protest) | 焦虑型依恋系统被分离信号激活时，用放大问题/放大负性情绪/连环消息/威胁分手来逼对方回应——这是抗议行为，不是事实。 |
| 回避型去激活策略(Deactivation) | 回避型依恋信号曾被拒绝，于是最小化问题、压抑情绪、不求助、转话题、刷手机——去激活不是没感觉，是感觉被系统抑制了。 |
| 分离焦虑传导链 | 童年分离焦虑经成人分离焦虑中介，显著预测焦虑型浪漫依恋——'怕失去'有可追溯的发育轨迹。 |
| 依恋×共情机制 | 元分析：安全依恋促共情，回避依恋抑共情，焦虑型共情两极摆动(高共情求接纳/低共情避痛苦)。 |
| 关系正念缓冲器(RM Buffering) | 焦虑轴被身体接触/伴侣支持/正念缓冲，回避轴被感恩/积极体验/非语言在场缓冲；关系正念双轴通用。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
