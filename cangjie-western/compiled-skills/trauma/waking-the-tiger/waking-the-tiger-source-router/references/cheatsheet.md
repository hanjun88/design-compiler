# 决策规则速查 — Waking the Tiger: Healing Trauma

| 能力 | 一句话规则 |
|---|---|
| 僵住是第三种生存反应（去羞耻的生物学解释） | 僵住不是懦弱，是战逃失效时的第三套保命程序，本应短暂、走完即释放。 |
| 动物自然释放观察：自愈是默认设置 | 野生动物遭遇威胁后会颤抖放电、回到基线；人卡住是因为动作被阻止，而非天生脆弱。 |
| 资源先行：先建立可退回的安全躯体锚 | 碰创伤之前，先在身体里找到一个真的能感到安全的锚，并约定随时退回。 |
| 滴定：一滴一滴靠近，防淹没与二次创伤 | 像化学滴定一样一滴一滴引入创伤材料，主观强度到 6-7/10 就退回资源。 |
| 摆动：在激活与资源间往返扩窗 | 让注意力在一个轻微不适点和一个资源点之间来回摆，反复练习'能靠近也能退回'。 |
| 完成被阻断的本能动作（完成未完成的动作） | 识别身体想做却当年没做成的动作冲动，在安全里放慢把它做完，让身体收到'已完成'反馈。 |
| 识别并允许放电信号：颤抖/打哈欠/流泪/长叹是自愈 | 练习中出现颤抖、打哈欠、流泪、深长叹息时，那多是身体在放电，别压住，让它走完。 |
