## I — Interpretation
Levine 注意到一件事：在世界各地的传统疗愈仪式里，都能看到和 SE 临床一样的元素——颤抖、呼吸变化、被社群"领回身体"（萨满所谓 soul retrieval / 灵魂召回）。这说明疗愈**很少是一个人关起门来完成的**：被亲友/社群在场看见、被一套有节奏的仪式容纳，本身就是疗愈容器。用多迷走的话说，安全的他人在场会激活腹侧迷走（社会参与系统），给系统一个"可以安全地释放"的平台。因此，把"疗愈"等同于"我必须自己扛过去"本身就是创伤的孤立感在作祟——主动、适度地引入安全的他人、稳定的支持结构，不是软弱，而是符合人类生物学的疗愈要素。

## A1 — Application Example
开放文献（LE02 L0023）：传统疗愈者在社群在场下把断连的创伤者"领回身体"，因为亲友连接是疗愈的内在组成部分。现代对应物不是照搬仪式，而是：在有信任的陪伴/小组/治疗关系中处理创伤，而非独自反复琢磨。

## A2 — Future Trigger
- 场景：对方"什么都自己扛、觉得跟人说没用/会麻烦别人"，或一个人做身体练习时总在最关键处卡住。
- 语言信号："我不想麻烦别人 / I don't want to burden anyone"；"我一个人处理就行 / I should do this alone"；"我试过一个人冥想但没用 / it doesn't work when I'm alone"。
- 与相邻能力区分：
  - 与 `life-force-goodness` 分工：那张讲"重新连接到善性/生命"的意义层；本卡讲**连接谁、靠什么容器**——他人与社群在场。
  - 与 Waking the Tiger `resourcing-first` 分工：那张找**内在/身体**锚点；本卡把资源扩展到**人际/社群**锚点（腹侧迷走来源）。

## E — Execution
1. 识别孤立：对方是否把疗愈当成只能独自完成的任务。完成标准：说出"一个人扛"的模式。
2. 引入/强化一个安全他人锚：一个可信任的人、稳定的小组、或专业治疗关系。完成标准：指定一个具体的、安全的人际支持点。
3. 在这个容器里做身体工作，而不是孤立硬练。完成标准：下次练习时知道"我不是一个人在做"。
- 输入：孤立疗愈/怕麻烦别人的模式。输出：一个被纳入疗愈的安全人际/社群锚。
- 红线：选择的"容器"必须真的安全、知情；不在不安全/操纵性关系里做创伤工作。

## B — Boundary
- 反场景：照搬萨满仪式/诱导进入强烈意识状态——本卡只取"安全关系与社群在场"这一普遍要素，不复制仪式。
- 失败模式：把"要社群"变成依赖或逼迫对方向不合适的人敞露创伤细节。
- 作者盲点：跨文化内容为 Levine 的人类学观察，非可操作手册；尊重各文化原意，不挪用。
- 红线：人际资源是补充，重度创伤仍需专业治疗关系。
