# SIBAM 五通道碎片化：为什么"身体在、意义不在"（SIBAM Fragmentation）

## R — Reading

- `raw/legal_open/LE03_payne2015.txt` L0020: "Procedural memory ... is not accessible via thoughts or images but via physical sensation (proprioception and kinesthesis)."
- `raw/legal_open/LE02_ives2020.txt` L0021: "The aim is to access the body memory of the event, not the story."

## I — Interpretation
一次完整的体验由五个通道同时构成：**S**ensation（身体感觉）、**I**magery（意象）、**B**ehavior（行为/动作冲动）、**A**ffect（情感）、**M**eaning（意义/解释）。健康时五者是连在一起的：感到紧→浮现画面→涌起情绪→知道这意味着什么。创伤会把它们**撕裂**：人可能只剩一团身体感觉却讲不出故事（纯躯体化）；或只剩"我有罪/我不够好"的意义感却感觉不到身体（理智化）；或只有动作冲动而无情感。Levine 的工作假设是：五通道被解离后，要从**感觉(S)**这个最直接的入口重新接通——因为创伤是以程序/躯体记忆编码的，它不通过想法和意象被触及，只能通过身体感觉。这解释了为什么"把故事想明白"不一定带来疗愈。

## A1 — Application Example
Simon 个案（LE03 L0007, L0020）：治疗不先追事故的"意义/故事"，而是从肩膀紧、手抖这个**感觉通道**入手；随着感觉被允许和摆动，动作（转方向盘）、情感（泪、怕）、意义（"我活下来了"）才逐步重新接通。这是 SIBAM 碎片化后从 S 入口重连的示范。

## A2 — Future Trigger
- 场景：对方"道理都懂、也能讲出经过，但身体照样过不去"；或"只剩身体难受却说不出是什么情绪"；或"全是自责，却感觉不到自己的身体"。
- 语言信号："我知道发生了什么但就是过不去 / I know what happened but it doesn't help"；"身体难受但我说不出情绪 / my body hurts but I can't name the emotion"。
- 与相邻能力区分：
  - 与 `unspoken-voice-interoception` 分工：那张讲"身体优先于语言"的原理；本卡用 SIBAM 解释**哪几个通道断了**，并定位从 S 重接。
  - 与 Waking the Tiger `biological-completion` 分工：那张做"完成动作(B)"；本卡诊断 S/I/B/A/M 哪几格缺失，再决定从哪格入手。
  - 与 sibling `cap.complex-ptsd.detect-dissociation` 分工：那张识别解离发作；本卡给"体验通道被撕裂"的结构化描述。

## E — Execution
1. 五通道盘点：此刻——身体感觉(S)有吗？画面(I)？动作冲动(B)？情绪(A)？意义/解释(M)？完成标准：能指出哪几格在场、哪几格缺失/麻木。
2. 从在场的、最弱负担的一格入手；若身体感觉还在，优先从 S 开始（这是创伤记忆的编码通道）。完成标准：选准一个入口格。
3. 让该通道被温和陪伴，观察相邻通道是否自然跟上（情绪、画面、意义逐步浮现）。完成标准：出现两格以上重新连接的迹象。
- 输入：一个"想明白却疗愈不了"的困扰。输出：五通道盘点 + 选定的重接入口。
- 红线：不逼某一格强行浮现（如硬要"说出意义"）；哪格在就从哪格开始。

## B — Boundary
- 反场景：把 SIBAM 当固定问卷逐项审问——它是理解工具，不是填表。
- 失败模式：硬从"意义"通道做认知重构，跳过身体，结果重蹈"道理懂但没用"。
- 作者盲点：开放文献对 SIBAM 的逐步临床操作描述有限；本卡是诊断框架，操作仍走 SE 治疗师引导。
- 红线：觉察/理解用途，不替代创伤治疗。
