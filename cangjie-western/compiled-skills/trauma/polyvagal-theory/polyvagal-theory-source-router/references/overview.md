# BOOK_OVERVIEW — The Polyvagal Theory in Therapy (Deb Dana)

> 合法开放底本蒸馏，非商业原文。底本：Porges PMC3108032 + Haeyen PMC11150850（Porges 评审）+ Dana 操作化公开资料。

## 阶段0 — Adler 四步

### 1. 结构（这是一本关于什么的书）
Deb Dana 把 Stephen Porges 的多迷走神经理论翻译成临床可用的"神经系统语言"。全书骨架：
- 自主神经系统按进化层级组织为三条通路：腹侧迷走（VVC，社会参与/安全）→ 交感（SNS，动员/战逃）→ 背侧迷走（DVC，冻结/解离/崩溃）；
- **神经感受（neuroception）**：无意识地在安全/危险/生命威胁间扫描，快于意识；
- 治疗不是"讲道理"，而是帮助客户**追踪状态、识别梯级、沿正确方向上梯**；
- 实践循环：调节（regulation）→ 连接（connection）→ 沟通（communication）；Dana 称之为 Rhythm of Regulation。

### 2. 解释（作者的核心主张）
- **层级/Jackson 递降**：较新环路抑制较旧环路；高阶失效时低阶浮出（P01 L11）。
- **方向不可逆跳**：从背侧崩溃不能直接到腹侧安全，必经交感动员（P03 L9-11）。
- **Glimmers（微光）**：被创伤窄化的威胁注意会错过日常安全瞬间；主动记录微光训练腹侧可达性（P03 L12）。
- **状态非性格**：三个状态都是适应性的，腹侧不是"唯一好状态"（P03 L13）。
- **共调节优先**：治疗师/安全他人的神经系统是最强调节工具（P03 Tips）。

### 3. 批判（局限与安全边界）
- 神经生理学有争议：Porges 关于腹侧迷走髓鞘化/哺乳类独有社会参与系统的具体主张被比较解剖学家质疑（P02 L8, P03 L14）。诚实定位：这是**有用的临床启发式地图**，不是已定论的生物学。
- 不能用作自我诊断或替代精神科评估；急性解离、自杀危机、创伤闪回需专业干预。

### 4. 应用（agent 如何把它变成能力）
转化为"迷走神经状态追踪与调节状态机"：
1. 三梯级状态定义 + 行为线索；
2. 实时状态追踪日志（时间/梯级/触发/身体线索/回升）；
3. 按当前梯级选择调节菜单；
4. 背侧上升必经交感的方向规则；
5. glimmer 日记训练腹侧可达性；
6. 社会参与系统激活技术（声音、面部、呼吸延长呼气）。
所有能力卡 B 段含安全红线。
