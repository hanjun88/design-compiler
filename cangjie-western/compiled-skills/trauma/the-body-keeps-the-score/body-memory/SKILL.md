# 躯体记忆：身体记住创伤的神经生物学核心论题

## I — 义理与心理学对齐（Interpretation）
van der Kolk 的核心命题是：创伤不只"记在脑子里"，更"刻在身体里"。三件事同时发生：
1. **脑三改变**——杏仁核（警报器）过度激活、内侧前额叶（刹车）下线、海马（情境化/时间标记）萎缩，导致"警报常开、刹车失灵、回忆像现在发生"。
2. **躯体化外显**——创伤以慢性疼痛、睡眠障碍、胃肠/心血管/肌肉骨骼问题等躯体症状表达，因为自主神经系统长期处于高唤起。
3. **自我调节与关系受损**——复杂性创伤者的情绪调节、注意力、关系能力同时受损（L00037 直接引用 van der Kolk 1996）。
这意味着：**只做谈话疗法不调身体，等于只修刹车不换警报器**；康复必须同时作用于躯体感知、自主神经调节和叙事加工。这是理解后续多路径康复（EMDR/瑜伽/神经反馈/身心疗法）的理论底座。

## A1 — 判定算法与 AST 证明节点
1. 观察是否同时存在：(a) 高唤起/惊跳反应、(b) 无法自我安抚/情绪刹车失灵、(c) 躯体症状（睡眠/疼痛/胃肠）、(d) 创伤史或 ACE 累积；
2. 排除急性器质疾病与药物因素后，将症状解释锚定到"脑-身创伤回路"而非"性格缺陷/装病"；
3. 输出解释框架："你的身体在真实威胁下学会了过度警报，现在安全了但身体还不知道"；
4. 康复取向：先躯体着陆/调节，再叙事加工。
AST 节点：`exposure → brain-loop (amygdala↑/PFC↓/hippocampus↓) → hyperarousal + somatic complaints → somatic-first stabilization → narrative processing`。

## A2 — 业务场景与 NVC 提示
**触发语**："为什么我明明知道现在安全了，身体还是发抖/睡不着/像惊弓之鸟？"｜"我胸口一直堵着，但医生说我心脏没问题"｜"我脑子里明白，可身体就是放松不下来"。
- 场景① 伴侣/家人被创伤后躯体反应困扰：解释为身体记忆而非装病。
- 场景② 用户对"心理问题"抵触时：用"身体把创伤存下来了"去病理化入口。
- 与相邻卡区分：
  - 与 `brain-body-loop`：本卡是**总论题**（身体为何记住创伤 + 为何必须躯体介入），brain-body-loop 是**脑三改变**的具体神经机制拆解。
  - 与 `somatic-first`：本卡解释"为什么"，somatic-first 处理"查不出原因的身体疼该先做什么"。
  - 与 `multi-modal-recovery`：本卡是理论底座，multi-modal-recovery 是具体康复路径选择。

## E — Execution（可执行步骤）
**输入契约**：用户报告创伤史 + 躯体症状/高唤起 + "知道安全但身体不相信"的体验。
1. **确认脑-身回路三症状共现**：高唤起（惊跳/失眠/易怒）+ 情绪刹车失灵（一点就炸/停不下来）+ 躯体化（疼痛/胃肠/呼吸）。完成标准：至少 2/3 领域有报告。
2. **去病理化解释**：用一句话说"你的身体在真实危险时学会了过度警报，现在安全了但身体还不知道"。完成标准：用户能复述这句话并表示被理解。
3. **优先躯体着陆而非谈话加工**：推荐先做呼吸/肌肉放松/感官锚定，再谈创伤内容。完成标准：用户能说出至少 1 个可立即使用的躯体着陆动作。
4. **转介判断**：若躯体症状首次出现、无创伤史、或伴红旗体征（胸痛/急腹症/神经缺损），先器质排查。
**输出契约**：一段"脑-身回路解释 + 躯体优先康复取向 + 下一步转介/自助建议"。

## B — Boundary（边界与红线）
- **禁止用神经解释否定真实危险**：脑-身回路解释不适用于当前仍处虐待/暴力情境的人——那不是"身体记错了"，那是真实威胁。
- **不可替代器质排查**：躯体症状必须先并行排除器质疾病（心脏病/甲状腺/神经系统），不得直接归因于创伤而延误医疗。
- **不做个体脑成像诊断断言**：不告诉用户"你的海马萎缩了"或"你杏仁核过度活跃"——这些是群体层面研究发现，不是个体诊断。
- **不把创伤躯体化神秘化**：不是所有慢性疼痛都是创伤记忆；排除器质后才考虑心理-躯体路径。
- **安全红线**：本卡为心理教育与康复导向，不替代精神科诊断、药物治疗或急诊；伴自伤/自杀/急性精神病性症状时立即转危机干预。
