# 决策规则速查 — Complex PTSD: From Surviving to Thriving

| 能力 | 一句话规则 |
|---|---|
| 4F 创伤类型识别（战/逃/僵/讨好）与互补康复 | 战/逃/僵/讨好 4F 是固定默认防御；康复方向是向互补极生长，不是消灭主型。 |
| 情绪闪回发作时的 13 步当下化处置 | 情绪闪回=退行到童年受困状态；按命名→安全→边界→躯体着陆→抑制批判→哀悼→社会缓冲顺序重建前额叶调控。 |
| 触发/闪回识别与着陆协议 | trigger 唤起记忆，flashback 如临当下；先回到此时此地，再处理内容。 |
| 自伤/自杀风险分流（安全红线） | 先分清自伤有没有自杀意图，两种风险都要评估并给安全网。 |
| 关系重演诊断（此时—彼时错位） | 当下关系里反复上演的旧剧本，先认出它来自过去，才能跳出。 |
| 创伤反应正常化（去病理化同盟） | 先把'对异常事件的正常反应'这件事讲清楚，再谈改变。 |
| 情绪两极端与最优唤醒窗 | 情绪不是越多越好也不是越少越好，把人带回'能处理'的唤醒带。 |
| 解离识别与回收 | 突然断线、情感扁平、人在心不在，先回收注意，不追问态度。 |
| 回避循环与支持系统重建 | 回避短期止痛、长期养恐；越早重建安全联结，越能破循环。 |
| 复杂性创伤画像与延迟发作 | 长期、重复、发生在关系里的创伤有自己的画像：情绪调节、关系、自我组织三重受损，且可能延迟爆发。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
