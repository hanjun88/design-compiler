# 决策规则速查 — The Seven Principles for Making Marriage Work

| 能力 | 一句话规则 |
|---|---|
| 末日四骑士识别 | 批评→蔑视→防御→筑墙；蔑视是离婚头号预测因子。 |
| 负性恒温器与 5:1 魔法比率 | 过热（冲突轰炸）或过冷（情感抽离）都要重置；目标正负互动比 ≥5:1。 |
| 爱情地图构建 | 幸福伴侣不是更爱，而是更知道对方在想什么。 |
| 修复尝试识别与回应 | 任何阻止负面升级的言行都是修复尝试；先接住，再谈对错。 |
| 背叛后的修复路径 | 背叛后先处理伤害、再重建信任、最后处理触发点；PTSD 样症状须被看见。 |
| 金钱对话的"我们对问题"重构 | 从"我们彼此对立"转向"我们对问题"，财务对话才可能成功。 |
| 激情消退与情感外遇 | 未被听见的话会自己找耳朵；把向外倾诉转回向内对话。 |
| 关系商业计划 | 健康关系像成功企业：有商业计划（愿景+分工+复盘），不靠运气滑行。 |
| 情绪教练式冲突调解 | 命名情绪→共情验证→设边界→共同找解。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
