# GLOSSARY — The Seven Principles for Making Marriage Work

| 术语 | 英文 | 定义 |
|---|---|---|
| 末日四骑士 | Four Horsemen | 批评、蔑视、防御、筑墙；预测关系破裂的行为链条。 |
| 批评 | Criticism | 把对事件的不满升级为对对方人格的人身攻击。 |
| 蔑视 | Contempt | 从道德制高点讽刺、挖苦、翻白眼；离婚头号预测因子。 |
| 防御 | Defensiveness | 被指责后找借口、反把责任推给对方。 |
| 筑墙 | Stonewalling | 听者抽离、闭嘴、转身；生理淹没后的反应。 |
| 5:1 魔法比率 | Magic Ratio | 每次负性互动需 ≥5 次正性互动缓冲。 |
| 负性恒温器 | Negativity Thermostat | 关系温度自我调节；过热=冲突升级，过冷=情感抽离。 |
| 生理淹没 | Flooding | 情绪生理过载，此时大脑无法理性对话；筑墙的生理基础。 |
| 爱情地图 | Love Maps | 对伴侣内在心理世界（童年/压力/梦想/恐惧）的持续详细认知。 |
| 修复尝试 | Repair Attempt | 任何阻止负面升级的言行；持续失败=不幸未来。 |
| 修复清单 | Repair Checklist | 平静时一起定制的"哪些话能让我降温"清单。 |
| 可解决问题 | Solvable Problem | 有具体解决方案的冲突；目标是妥协。 |
| 永久问题 | Perpetual Problem | 源于个性/价值观差异的长期冲突（约占 69%）；目标是对话而非解决。 |
| 共同意义 | Shared Meaning | 夫妻共同创造的象征、仪式、角色与人生故事。 |
| 情感外遇 | Emotional Affair | 婚姻不满持续向婚外第三方倾诉；未曝光时咨询多失败。 |
| 背叛修复 | Betrayal Recovery | 外遇后处理伤害→重建信任→处理触发点的三步路径。 |
