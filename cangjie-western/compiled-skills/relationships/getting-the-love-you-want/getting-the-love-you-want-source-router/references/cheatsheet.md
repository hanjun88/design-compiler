# 决策规则速查 — Getting the Love You Want

| 能力 | 一句话规则 |
|---|---|
| 意象匹配：你为什么偏偏爱上"这种"人 | 你选的伴侣不是随机，是潜意识按童年 imago 选的；看清楚这个剧本就不再被它无声驱动。 |
| 画出你的 Imago 地图：父母负面特质 + 被压抑的自我 | 列父母负面特质表、被压抑自我表、未满足需求表，映射到现任，把潜意识拿进意识。 |
| 权力斗争阶段：热恋结束不是关系坏了，是开始了 | 定位关系阶段（浪漫/斗争/意识/创造），把"选错人"的念头翻成"imago 剧本重演"。 |
| Imago 对话三步：镜像 → 验证 → 共情（核心操作卡） | 约时间→镜像逐句复述→验证逻辑→共情一个词→换角色；Receiver 全程不辩护不建议。 |
| 再浪漫化：用具体小事重建正向循环 | 账户小步充值：美好记忆清单+对方让我开心的事+每周共同活动+固定感恩话。 |
| 把怨恨翻译成请求：从"你从来不"到"我需要" | 每条怨恨底层都有一个具体未满足需求；翻成"当___时你能不能___让我感到___"。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
