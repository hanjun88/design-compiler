# GLOSSARY — getting-the-love-you-want

| 术语 | 英文 | 简释 |
|---|---|---|
| 意象/Imago | Imago | 童年形成的潜意识伴侣图，混合父母负面特质+被压抑的自我。 |
| 意识关系 | Conscious relationship | 从"无意识重演童年"到"有意识共同成长"的关系。 |
| 权力斗争期 | Power struggle | 热恋投影脱落后，双方试图改造对方的阶段。 |
| 浪漫期/热恋期 | Romantic/honeymoon | imago 投影阶段。 |
| 意识期/重承诺 | Awareness/recommitment | 从"你要改"到"我们一起理解"。 |
| 镜像 | Mirroring | Receiver 逐句复述 Sender，不加评论。 |
| 验证 | Validation | Receiver 说"你的逻辑通"，不要求同意。 |
| 共情 | Empathy | Receiver 猜 Sender 的感受，一个词，然后核对。 |
| Sender/Receiver | Sender / Receiver | 对话角色；Sender 说，Receiver 听，结束后交换。 |
| 童年创伤 | Childhood wound | 父母/照顾者造成的情感伤害。 |
| 被压抑的自我 | Disowned self | 为适应童年环境而关掉的自己的部分。 |
| 正向请求 | Positive request | 把"你从来不X"翻成具体可执行的"你能不能在___时做___"。 |
| 再浪漫化 | Re-romanticization | 刻意积累正向互动账户。 |
| 未满足需求 | Unmet childhood need | 童年最缺的东西，在成年关系中反复索要。 |
