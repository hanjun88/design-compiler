# 决策规则速查 — Psychology and Life (津巴多普通心理学)

| 能力 | 一句话规则 |
|---|---|
| 认知失调降减：识别伴侣冲突中的自我辩护循环 | 认知冲突引发负性情绪；识别情绪即可预测自我辩护路径，插入投入型重新整合替代标签化。 |
| 基本归因偏差：把"他的为人"和"他的处境"分开 | 对伴侣行为先说"他就是X"时，停一下，列至少3个情境解释，资源不足时推迟人格判决。 |
| 确认偏误：主动找"反证"，而不是只找"证据" | 写下你对伴侣的结论，强制列3条具体反证，定义"什么会改变我的想法"。 |
| 服从与责任扩散：识别"我只是照做"的道德脱钩 | 拆"我只是照规矩/中间传话的"免责台词，把被伤害的人拉近、找不服从同伴、拒绝升级命令。 |
| ELM 说服双路径：在对方"能听"和"想听"时再谈正事 | 谈重要事前先查对方能力（累/怒/忙）和动机（在乎吗），任一红灯就约下次，不硬谈。 |
| 关系冲突认知偏误扫描总入口 (router) | 冲突后按5问自检：自我辩护？人格判断？证据单向？责任扩散？时机对吗？再决定开口。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
