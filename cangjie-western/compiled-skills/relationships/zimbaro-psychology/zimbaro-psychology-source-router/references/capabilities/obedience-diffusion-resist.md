# 服从与责任扩散：识别"我只是照做"的道德脱钩

## I — Interpretation
Milgram 研究的真正教训不是"人很坏"，而是**情境结构**让人放弃道德判断。元分析告诉我们八个杠杆，其中最被低估的是：(1) **间接性**——当你的角色只是"读题的人"，按按钮的是另一个人，服从率飙升（92.5%）；(2) **亲密度**——受伤害的人是陌生人还是亲友，服从率差4倍；(3) **没有同伴拒绝榜样**时，人很难独自反抗；(4) **权威给明确升级命令**时，普通人也会一路升级。在亲密/家庭/职场关系里，这对应一种隐蔽的服从：你接受了对方（或父母、家族、"传统""面子"）对情况的定义，不再自己判断对错。"我只是顺着他""家里就该这样""我妈说你应该…"——这就是关系版的责任扩散。

## A1 — Application Example
合成演练：一对夫妻，丈夫的家族一直要求儿媳过年必须回男方老家、必须忍长辈的挑剔。妻子起初不同意，丈夫说"我也没办法，这是规矩""我爸就那样，忍忍就过去了"。这是典型的**间接性 + 权威一致性**：丈夫把自己定位成"传话的人"，不做道德判断，让妻子直接承受。健康的抵抗结构是：(1) 丈夫不再做"中间人"，而是和妻子站在一起面对家族（亲密度翻转：被保护的人变近）；(2) 找到一个"不服从的同伴榜样"（另一个敢于说不的亲戚/朋友）；(3) 拒绝"我只是照做"的角色。

## A2 — Future Trigger
**场景**：你发现自己在关系/家庭/职场中重复一句免责台词，把责任推给"规矩/长辈/对方/大家都这样"；你做了一件你自己不认同的事，但告诉自己"没办法"。
**语言信号**：
- "我只是照做/我没办法" / "I was just following orders / I had no choice"
- "我也不想，但___就是这样" / "I don't like it either, but that's just how ___ works"
- "我只是中间传话的" / "I'm just the messenger"
- 你在一个系统里伤害了一个具体的人，但你从没和那个人直接面对面。
**与相邻能力区分**：FAE 是"我误判他的人格"；本卡是"我放弃了对自己行为的道德判断，把自己外包给权威/系统"。

## E — Execution
1. **抓免责台词**（1分钟）：写下你最近一次做了自己不认同的事时说的免责句。完成标准：一句具体的话。
2. **拆间接性**（2分钟）：问自己——"如果必须由我本人直接面对那个被伤害的人（而不是隔着一层），我还会做吗？"完成标准：是/否 + 一句理由。
3. **找一个不服从榜样**（2分钟）：谁在这个系统里曾经说过"不"，结果如何？写下这个人 + 他/她的结局。完成标准：≥1个真实榜样。
4. **恢复亲密度**（行动）：把被你间接伤害的那个人拉到"近处"——当面、知道名字、知道感受。完成标准：一次直接对话或一次具体的道歉/修复动作。
5. **拒绝升级命令**：下次权威/对方要求你"再进一步"时，**不立即答应**，说"我需要想一想"。完成标准：一个具体的延迟回应。

## B — Boundary
- 反场景：在真正的虐待/控制关系里，一方对另一方施加 Milgram 式服从（威胁、羞辱、隔离），"识别服从结构"不能用来责怪受害者"你为什么不反抗"。此时安全评估和资源优先。
- 失败模式：把这个框架用来叛逆一切权威（包括合理的边界和法律）。Milgram 研究说的是"伤害他人时的责任扩散"，不是"所有规则都该违反"。
- 教材常误读：元分析指出"机构声望(Yale)"和"权威合法性"被高估；真正重要的是**直接命令 + 无拒绝同伴 + 受害者遥远**。别背错知识点。
- 不替代专业帮助：长期处于高度控制/服从的关系中，建议找有 DV 经验的咨询师。
