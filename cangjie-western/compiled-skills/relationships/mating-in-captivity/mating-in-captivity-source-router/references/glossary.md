# GLOSSARY — mating-in-captivity

| 术语 | 英文 | 简释 |
|---|---|---|
| 色情智力 | Erotic intelligence | Perel 造词；不是性技巧，是和 aliveness/想象/玩心的关系。 |
| 亲密 | Intimacy/Security | 亲近、融合、可预测、保护、责任。 |
| 欲望 | Desire/Eros | 距离、自主、新奇、未知、想象。 |
| 活着感 | Aliveness | 生命力、活力、振动感；色情的真正所指。 |
| 死亡焦虑 | Mortality anxiety | 丧失/中年/重病触发"就这样了吗"，常驱动外遇或新冒险。 |
| 有控制的冒险 | Controlled adventure | 在厚安全容器内有意制造一点未知/距离。 |
| 玩 | Play | "当风险变得好玩"；play 需要安全，但不玩就没有色情。 |
| 侦探性问题 | Detective questions | 地点/频率/身体细节——只增加痛苦。 |
| 调查性问题 | Investigative questions | 意义/动机/体验——指向未来。 |
| 主关系 vs 外遇 | Primary vs affair | 外遇的"欲望机器"来自不可得+秘密+禁忌，不一定是那个人。 |
| 危机即入口 | Crisis as doorway | 背叛暴露后可能成为"第二段婚姻"的起点。 |
| "我让自己关机/开机" | I turn myself off/on | Gina Ogden 句式；把欲望主权从伴侣拿回自己身上。 |
| 配偶化/亲情化 | Spousalization | 把情人变成家人/室友；C 象限。 |
