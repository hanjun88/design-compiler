# 决策规则速查 — The Changing Sky

| 能力 | 一句话规则 |
|---|---|
| 行运的象征层非决定论安全阀 | 行运是镜子不是地图，是季节不是剧本；不预测事件，不替代临床判断。 |
| 行运盘作为移动的象征镜子 | 行运=天上行星当前位置与本命盘的象征相位互动，是移动镜子，不预测事件。 |
| 外行星行运的心理危机触发点 | 土星=结构重建，天王=个体化突破，海王=溶解迷茫，冥王=剥离转化；同一行运可活成成长或危机。 |
| 内行星短期 vs 外行星长期时间尺度 | 内行星行运=日周级天气，外行星行运=月年级季节。 |
| 五相位象征光谱 | 合=融合，六合=机会，刑=张力，拱=流动，冲=极化。 |
| 生命周期行运里程碑 | 土星回归(~29.5岁)、天王星对冲(~42岁)、木星回归(~12年)是西方占星的人生节气。 |
