# 决策规则速查 — The Inner Sky

| 能力 | 一句话规则 |
|---|---|
| 出生图的非决定论安全阀 | 出生图是对你个人最充实人生的描述+误用资源时如何自毁的地图，不是命运判决书。 |
| 原始三元组优先法（Sun/Moon/Asc） | 不要从太阳星座开始；先抓 Sun（身份）+Moon（情绪）+Asc（面具）的1728种组合骨架。 |
| 行星×星座×宫位三元合成语法 | 行星=驱力(what)，星座=美德(how)，宫位=课堂(where)，三者合读成一句话。 |
| 星座=待养成的美德 | 星座不是"你是什么样的人"的标签，而是"你被邀请去活出的美德"。 |
| 行星=十位心理驱力老师 | 行星是心理驱力+老师：Sun=自我，Moon=情绪，Mercury=思考，Uranus=个体化，Neptune=超越。 |
| 内行星个人性 vs 外行星世代性 | 外行星星座位=世代主题（如海王13年），宫位与相位才是个人化。 |
| 星座符号的现代原型转译练习 | 把传统星座动物意象翻译成现代原型词（艺术家/说书人/侦探），可自创。 |
