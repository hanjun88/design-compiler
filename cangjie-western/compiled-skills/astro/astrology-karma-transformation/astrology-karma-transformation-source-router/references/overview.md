# book/overview.md — Astrology, Karma & Transformation (侧车摘要)

Arroyo (1978) 在 Rudhyar 人文占星谱系上，把占星从预测技术重写为"心理能量的成长象征语言"。核心:
1. 星盘=成长地图(潜能/张力)，非命运剧本 [05 L0005-11]。
2. 业力=意识因果律，重复存在方式被意识化后转化 [05 L0012-14]。
3. 四元素(火/土/风/水)=四种存在方式，主导=顺手，缺失=成长 [06]。
4. 南北交点=舒适区旧模式 vs 成长边缘 [07]。
5. 外行星(土/天/海/冥)=深度转化催化剂，与荣格死-重生同构 [04,02]。
边界: 学术视占星不科学；习惯性反刍可致焦虑。全部能力 is_actionable=false。
