# 决策规则速查 — Synastry: Understanding the Hidden Forces Behind Astrological Compatibility

| 能力 | 一句话规则 |
|---|---|
| 比较盘作为两体对话 | 比较盘=两本命盘直接叠加不合并, 读 A 行星与 B 行星之间的交叉相位, 看两人如何相互激活(街面层) |
| 组合盘作为第三实体 | 组合盘=两人行星数学中点构成的'关系本身'盘, 是第三实体, 不属于任何一方 |
| 组合盘上升与关系面具 | 组合盘上升指示关系初见环境、共同启动方式与对外面具; 与上升成相的行星最被外人一眼看到 |
| 组合盘日月与关系核心 | 组合太阳=关系核心身份与目的; 组合月亮=关系情感基调与安全感; 日月相位=核心和谐度 |
| 组合盘相位动力模式 | 组合相位揭示动力模式: 金火拱=流畅愉悦, 日火刑=自我碰撞, 海王硬相=理想化幻灭, 冥王相=控制阴影 |
| 组合盘宫位重心 | 一宫聚≥3行星(尤含日月)为强调宫; 宫位把相位动力落到具体生活领域 |
| 组合盘的象征层定位：关系镜像非判决 | 组合盘=关系能量场的镜像, 不预测成败不决定分合; 满盘刑相不等于注定完蛋, 信息不是判决 |
