# BOOK_OVERVIEW — Internal Family Systems Therapy (Richard C. Schwartz)

> 合法开放底本蒸馏，非商业原文。底本：Schwartz 本人 IFS Institute 开放文章 + IFS L1 课程大纲 + Psychology Today IFS 词条。

## 阶段0 — Adler 四步

### 1. 结构（这是一本关于什么的书）
IFS 把心智视为一个"内在家庭"——由多个相对独立的次人格（parts）组成的生态系统，围绕一个核心的、本自健康的 Self 组织。全书骨架：
- 心智是多重的（multiplicity），不是单一的；
- parts 分三类：Managers（管理者/前置保护者）、Firefighters（消防员/反应式保护者）、Exiles（流亡者/承载痛苦的年轻部分）；
- 核心是 Self（大写 S），以 8 个 C 品质显现；
- 疗愈路径：让 Self 从 parts 中分化出来 → 取得保护者许可 → 接近流亡者 → 见证并卸载（unburdening）。

### 2. 解释（作者的核心主张）
- **No Bad Parts**：没有坏的 parts。每个极端行为背后都是一个曾被生活事件逼入极端角色、但本意是保护的部分（E01 L4-6, L7-9）。
- **Self 本自具足**：即使严重创伤者也有 Self，只是暂时难以接近；疗愈不是"制造"健康，而是"释放"被 parts 遮蔽的 Self（E01 L10-12, L20）。
- **系统性**：parts 之间是关系网络，不是孤立症状；改变一个部分的角色会牵动整个系统。
- **方法核心动作**："step back"——请干扰的部分退一步，让 Self 在场（E01 L15-17, Diane 案例）。

### 3. 批判（局限与安全边界）
- 临床模型，非自助万能书；接触流亡者可能激活创伤记忆，需专业治疗师在场（E02 L7 明确"forcing access risks affect overwhelm and retraumatization"）。
- "Self" 概念带有现象学/灵性色彩，其神经科学证据仍在积累；本蒸馏将其作为**可操作的自我观察姿态**使用，而非形而上学断言。
- 对严重解离障碍（DID/OSDD）不适用自助场景，须由受训治疗师处理。

### 4. 应用（agent 如何把它变成能力）
转化为"次人格协调协议"：
1. 识别并命名 parts（地图）；
2. 检测 Self 是否在场（8C 信号）；
3. 用 step-back 请求干扰部分退让；
4. 取得保护者许可后才接近流亡者；
5. 见证 → 卸载 → 让部分选择新角色。
所有能力卡 B 段必须含安全红线：不替代专业治疗、创伤记忆处理需专业人士在场。
