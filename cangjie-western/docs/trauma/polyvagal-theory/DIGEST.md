# DIGEST — The Polyvagal Theory in Therapy (Deb Dana) 精华

一句话：**你的神经系统在一个三梯级梯子上移动——学会认出你在哪一梯，并按正确的方向爬。**

## 核心模型（状态机）
- 顶梯 腹侧迷走：安全、连接、可思考可感受。
- 中梯 交感：战逃、焦虑、愤怒、紧绷、扫描威胁。
- 底梯 背侧迷走：冻结、麻木、崩溃、解离——被困时的保命最后手段。
- **Neuroception** 在意识下持续把环境扫成安全/危险/生命威胁，先于思维。

## 可操作实践
1. **定位**：先问身体感觉，判断在哪一梯（autonomic-ladder）。
2. **追踪**：每刻记梯级/触发/身体线索/回升；过渡才是数据（state-tracking-log）。
3. **关键方向规则**：背侧崩溃时**不能直接放松**——先最小身体动作升到交感，再延长呼气接地升到腹侧（dorsal-climb-through-sympathetic）。
4. **菜单**：背侧→定向/起身/冷水；交感→延长呼气/接地/找安全的人；腹侧→注意品味（regulation-menu-by-rung）。
5. **微光**：每天记一个微小安全瞬间，4-6周调宽安全雷达（glimmer-practice）。
6. **激活**：放慢声音/放松脸/延长呼气/待在安全的人身边，激活社会参与系统（social-engagement-activation）。

## 安全与诚实
- 三态都适应性，腹侧不是唯一好状态。
- 多迷走神经生理有学术争议，这是**临床启发式地图**而非定论生物学。
- 急性解离/危机需专业帮助；本蒸馏为合法开放同主题权威底本。
