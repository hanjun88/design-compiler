# DIGEST — Waking the Tiger（Peter Levine, 1997）精华长文

> 非原书逐字，基于开放证据 LE01–LE04 重建。这是一本把创伤从"心理病"重新定义为"卡住的生存能量"的书，也是躯体体验疗法（Somatic Experiencing, SE）的入门操作手册。

## 一句话
面对生死威胁，身体动员了战/逃/僵三套程序；当程序被阻断、没走完，那股能量被冻在身体里成了症状；疗愈就是在安全关系里，一滴一滴地把它完成、释放。

## 核心直觉：野生动物为什么不留下创伤
Levine 观察到羚羊被猎豹逼近会僵死装死，威胁一去，就用波浪式的颤抖把逃跑能量散掉，然后回去吃草。实验更精确：**单有威胁或单有束缚都不致病，防御逃脱反应被阻止，才把系统锁死**。于是人不是"被事件弄坏了"，而是当时那个该跑完的生理周期没跑完——这给了人一个乐观假设：自愈设备还在，只是被卡住了。

## 四件套症状地图
任何创伤反应里都同时有四样东西：过度唤醒（油门）、收缩（收窄聚焦）、解离（与自己断连）、僵住/无助（刹车式瘫痪）。理解它们是为了判断现在该安抚、该唤醒还是该稳定，而不是急着挖记忆。

## 五把钥匙（可操作顺序）
1. **资源先行**：先在身体里找一个真能感到安全的锚——脚底踩地、背的支撑、被安全拥住的温度。创伤者的神经系统只会盯着紧、闷、慌；要主动训练它注意正性躯体标记，攒成能反复退回的"资源库"。
2. **滴定**：像化学滴定，一滴一滴靠近，只引入一点点身体感觉；主观强度到六七成就退回。创伤让人受伤不是因为材料，而是因为"太多、太快、太早"。
3. **摆动**：在轻微不适点和资源点之间来回——碰一下紧的地方，立刻回资源，再碰。反复练"我能靠近也能退回"，容忍窗被慢慢撑大。
4. **生物完成**：识别身体当年想做却没做成的动作——推、跑、躲、护住头——在安全里放慢把它补做完。身体收到"动作完成了"的反馈，交感才肯撤防。这不是重温记忆，也不是发泄，而是把中断的程序续完。
5. **允许放电**：颤抖、打哈欠、流泪、深长叹息、发热、呼吸变满，是系统在自我重置。别压住，也别怕——让它自然走完，结束后人通常更松。

## 与暴露疗法的根本分歧
Levine 明确反对让来访者在高恐惧唤醒下反复重温创伤故事：那会强化原始回路，是"完美风暴"。SE 走"自下而上"——从身体感觉入手，而非把故事讲透；目标不是记住事件，而是释放被锁住的能量。

## 诚实的边界
- SE 是对认知/暴露疗法的**补充**，不是替代。
- 截至 2021 年的循证综述：对 PTSD 症状有**初步、积极**效果，但研究质量混杂、缺高质量 RCT；"资源导向"与"触觉"被从业者点名为方法特色。
- 本批蒸馏面向非治疗师的**稳定化、去羞耻与知情理解**，所有主动技术都要求"轻微、可随时退回资源"；急性惊恐、解离、自伤自杀风险，先危机处置并转专业帮助。
- 那套"完成动作+放电"的核心技术，通常仍需受训治疗师在安全关系里引导。

## 与同系列其他书的关系
- **In an Unspoken Voice（2010）**：本书的理论深化，把同一套技术接上多迷走神经地图与"恢复善性/生命力量"的意义层。
- **Complex PTSD**：4F（战/逃/僵/讨好）分型、情绪闪回13步、着陆协议——补"识别急性发作"这一段。
- **Polyvagal Theory**：给"为什么背侧迷走=关机、腹侧迷走=社会参与"提供神经科学地基。
- **The Body Keeps the Score**：更宏观的创伤科学与脑科学背景。
