## 1. 结构 (Structural)

### 类型
心理占星行运解读手册（与 The Inner Sky 配套：Inner Sky 讲本命盘静态结构，Changing Sky 讲行星推进时的动态触发）。

### 一句话主旨
外行星（土/天/海/冥）行运是人生周期危机的象征触发点——它们不预言事件，而是像季节一样映照当下心理气候的转折色调；应对反射是把它当作镜子而非判决书。

### 骨架 (主要论点及其关系)
1. **行运的根本定位 = 移动的镜子**：天上行星当前位置与本命盘位置形成相位互动，映照当下心理气候，不是事件时间表。
2. **时间尺度分层**：内行星（日/月/水/金/火）行运持续数日至数周，是日常心理气候温度计；外行星（木/土/天/海/冥）行运持续数月至数年，是长生命周期象征刻度。
3. **相位 = 行运语气调色板**：合相=融合、六合=机会、刑相=张力、拱相=流动、对冲=极化；同一颗外行星行运，相位不同，心理语气不同。
4. **生命周期里程碑**：土星回归（~29.5 岁）、土星对冲（~15/44/74 岁）、天王星对冲（~42 岁）等是西方占星的人生时钟刻度，外行星行运在这些节点被激活。
5. **非决定论安全阀**：行运是镜子不是地图，是季节不是剧本；不预测疾病/死亡/婚恋成败/财富，不替代临床判断。
6. **应对反射（Forrest 进化立场）**：同一行运可活成成长也可活成危机，取决于人如何与它相遇——旧事物挡路才会被剥离，主动配合则可成为转化力量。

**论点之间的关系**: 递进——先立镜像定位（1）→ 再给时间分层（2）→ 再给相位语气（3）→ 再锚定人生时钟（4）→ 最后立非决定论伦理（5、6）。

### 作者要解决的核心问题
当一个人经历一段"人生好像出问题了"的时期，外行星行运可以作为什么隐喻工具，帮助他把这段混乱读成有结构的周期转折，而不是恐慌或宿命？

## 2. 解释 (Interpretive)

### 关键术语 (作者本人的用法)

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| Transit 行运 | 天上行星当前位置与本命盘位置的象征相位互动 | 常识把行运当"运势"；Forrest 把它当移动的镜子 |
| Inner planets 内行星 | 日/月/水/金/火，行运短（日数至周数），日常心理气候 | 常识不分内外行星；Forrest 用时间尺度分层 |
| Outer planets 外行星 | 木/土/天/海/冥，行运长（月数至年数），生命周期主题 | 外行星被误读为"大事件"；Forrest 视为长周期象征刻度 |
| Aspect 相位 | 两行星之间的角度关系，决定行运的语气 | 常识把相位当吉凶；Forrest 当色调调色板 |
| Saturn Return 土星回归 | 土星回到本命土星位置（~29.5 岁），结构重建节点 | 常被恐惧化为"危机"；Forrest 视为成人化结构重建 |
| Uranus Opposition 天王星对冲 | 天王星与本命太阳/天王星成 180°（~42 岁），个体化突破 | 常被标签为"中年危机"；Forrest 视为身份分化 |
| Mirror not Map 镜而非图 | 行运的根本定位：映照气候，不规划路线 | 核心安全阀 |

### 核心命题 (用自己的话)
1. 行运盘是一面移动的镜子，照见当下心理气候的色调，不是一张事件时刻表。
2. 时间尺度决定解读粒度：内行星行运看日常情绪天气，外行星行运看人生季节。
3. 相位决定语气：同样是土星行运，刑相是结构压力，拱相是结构支持，六合是结构机会。
4. 外行星行运在生命周期节点（土星回归、天王星对冲）被集中激活，形成可识别的人生时钟。
5. 同一行运可活成成长或危机——关键是人是否愿意配合转化，而非事件本身好坏。

### 论证链
Forrest 路径：先批判决定论（"占星预测不准"是因为大家把镜子当地图）→ 把行运重新定义为象征气候 → 用时间尺度分层（内/外行星）让解读有节奏 → 用相位五分类给语气 → 用生命周期里程碑把行运锚到人生时钟 → 最后立非决定论伦理。

## 3. 批判 (Critical) ★

### 作者的时代局限
- 1988 年原版，基于热带黄道；未讨论行运精确度数与现实事件的统计研究。
- 98 篇 AstrologyKing 底本为第三方公共占星教学，非 Forrest 原文——这是修复任务的证据弱点。
- 行运"影响持续 X 年"的说法来自传统占星共识，无实证。

### 作者的立场盲点
- 把外行星行运一律象征化为"成长机会"，对真实创伤性事件（丧亲、重病、暴力）如何落在行运窗口里缺乏严肃面对。
- "镜像非决定论"在临床上可能被用来淡化真实心理痛苦——需要明确让位临床通道。

### 未被证明的假设
- 行运相位与心理体验存在稳定象征映射——无实证，属传统共识。
- 土星回归=29.5 岁成人化、天王星对冲=42 岁个体化——是文化叙事，不是发展心理学实证结论。

### 最强反对意见
心理学/流行病学最强调：外行星行运与重大生活事件之间没有可重复的统计相关（如 Dean & Kelly 2003 双盲研究）；Forrest 的"镜像"框架虽避免了直接预测，但仍建立在不可证伪的象征映射上。最强反驳是：把行运当作"心理气候隐喻"有自我安慰价值，但不能替代真实的生活评估与临床判断。
