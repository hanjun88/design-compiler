# Synastry — GLOSSARY（全书共享术语词典·绑物理行号）

## 比较盘 / Synastry（比较盘）
- 来源 raw/legal_open/05_synastrychart_composite_vs_synastry.txt L00015–L00019
- 释义：两张本命盘直接叠加不合并，读 A 行星与 B 行星之间的交叉相位；"对话盘"，回答"两人在同一房间里会怎样相互激活"。

## 组合盘 / Composite Chart（组合盘）
- 来源 raw/legal_open/01_composite_chart_relationships.txt L00017
- 释义：两人每颗行星与关键点的数学中点构成的全新盘，"关系本身的盘"，第三实体。

## 第三实体 / Third Entity
- 来源 raw/legal_open/01_composite_chart_relationships.txt L00134–L00136；05 L00043
- 释义：组合盘属于"关系本身"这个介于两人之间的东西，不属于任何一方。

## 数学中点 / Midpoint
- 来源 raw/legal_open/05_synastrychart_composite_vs_synastry.txt L00040–L00042
- 释义：每对对应行星取黄道中点（如白羊10°+双子20°→金牛15°），构成组合盘行星位置。

## 交叉相位 / Cross-Aspects
- 来源 raw/legal_open/05_synastrychart_composite_vs_synastry.txt L00054–L00059
- 释义：比较盘中一方行星与另一方行星形成的夹角；五轴为日月、金火、土星、宫位覆盖、外行星接触。

## 组合盘上升 / Composite Ascendant
- 来源 raw/legal_open/01_composite_chart_relationships.txt L00020
- 释义：关系初见环境、共同启动方式与对外面具的象征刻度。

## 无相位行星 / Unaspected Planet
- 来源 raw/legal_open/01_composite_chart_relationships.txt L00021
- 释义：组合盘中无相位行星（如无相位太阳=关系方向感缺失）。

## 强调宫 / Emphasized House
- 来源 raw/legal_open/01_composite_chart_relationships.txt L00075
- 释义：一宫聚三颗及以上行星（尤含日月），关系能量集中领域。

## 海王理想化 / Neptune Idealization
- 来源 raw/legal_open/01_composite_chart_relationships.txt L00038
- 释义：组合盘海王硬相位初期近乎田园诗，随现实渗入而幻灭；期待被抬到非人的高度。

## 冥王控制 / Pluto Control
- 来源 raw/legal_open/01_composite_chart_relationships.txt L00072
- 释义：冥王接触个人行星→强迫性控制、情绪操纵、占有欲阴影。

## 戴维森盘 / Davison Chart
- 来源 raw/legal_open/05_synastrychart_composite_vs_synastry.txt L00079–L00081
- 释义：与组合盘不同的另一关系盘——取两出生时空的中点真实时刻起盘，是真实天文星图而非抽象中点。

## 非决定论 / Non-Determinism
- 来源 raw/legal_open/01_composite_chart_relationships.txt L00018；05 L00086–L00087
- 释义：与能量共事而非被能量统治；满盘刑相≠注定完蛋，信息不是判决。
