# BOOK_OVERVIEW — Wired for Love

- 作者: Stan Tatkin (PACT 创始人)
- 出版年: 2012
- 输出目录: cluster2_attachment/wired-for-love/
- 证据法: 合法开放同主题权威底本 (The PACT Institute 官网 + Stan Tatkin 官方书籍页 + 公开 PACT 培训师资料)，非原书原文

## 1. 结构
Tatkin 把依恋理论 + 神经生物学 + 情绪调节整合为 PACT (Psychobiological Approach to Couple Therapy)：
1. 成人伴侣天然互为"主要依恋对象"——不是恋爱选择，是神经系统设定；
2. 大脑 built more for war than love——威胁检测优先于连接；
3. PACT 用 Anchor/Wave/Island/Mixed 四种风格替代安全/焦虑/回避标签；
4. 关系目标不是"各自安全"，是 secure functioning——互为安全基地；
5. 十项原则把神经科学翻译为日常实操协议。

## 2. 解释
- **Anchor 安全型**: 情绪稳定，可亲近可独处，冲突后容易修复。
- **Wave 焦虑型**: 对距离高度警觉，抗议/升级/反复确认。
- **Island 回避型**: 压力下抽离，自给自足，情感需求被长期隐藏。
- **Mixed 混乱型**: 同时渴望又恐惧亲近，推拉循环。
- 核心机制: 伴侣互为 co-regulator——一个人的神经系统直接调节另一个人的威胁反应 (与 Johnson fMRI 研究一致)。

## 3. 批判
- 证据基础: PACT 临床培训体系成熟，但 RCT 研究少于 EFT；公开资料以临床描述为主。
- 风险: Tatkin 风格强势，容易被误读为"关系教条"。
- 盲点: 对 LGBTQ+ 关系、非婚伴侣、文化差异讨论有限。

## 4. 应用
关键任务:
1. PACT 四种风格识别
2. 伴侣作为主要依恋对象的神经生物学基础
3. 威胁-修复循环状态机
4. 连接邀请 (bid) 的识别与转向
5. 大脑负面偏见 (war vs love)
6. secure functioning 实操协议
7. 冲突后修复协议
