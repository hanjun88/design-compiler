# BOOK_OVERVIEW — Attached: The New Science of Adult Attachment

- 作者: Amir Levine (M.D.) & Rachel S. F. Heller (M.A.)
- 出版年: 2010
- 输出目录: cluster2_attachment/attached/
- 蒸馏执行者: cangjie-skill v2.5
- 证据法: 合法开放同主题权威底本 (NCBI Bookshelf / PMC 开放获取 / NICE 指南)，**非**原书原文

## 1. 结构 (Structural Outline)

本书将 Bowlby/Ainsworth 依恋理论从儿童情境平移到成人浪漫关系，核心命题：
1. 成人浪漫关系天然是依恋系统 (attachment system) 的激活场景；
2. 三种依恋风格 — 安全型 / 焦虑型 / 回避型 — 决定了伴侣如何寻求亲近、如何应对分离；
3. 焦虑型使用"激活策略" (hyperactivation / protest) 求亲近，回避型使用"去激活策略" (deactivation) 维持情感距离；
4. 焦虑×回避配对是关系中最常见的"追-逃"舞蹈；
5. 安全型可习得 (earned security)，关键是识别自己的策略并调整互动。

## 2. 解释 (Interpretive Outline)

- **主轴**: 不是"谁对谁错"，而是依恋系统的两套调节策略在同一关系里互相踩踏。
- **焦虑型**: 依恋系统过度激活 — 对分离信号过度警觉、反复确认、情绪爆发、寻求融合。
- **回避型**: 依恋系统去激活 — 抑制亲近需求、贬低伴侣、转向工作/手机/朋友。
- **安全型**: 依恋系统灵活 — 可亲近可独处，情绪可表达可调节。
- **诊断价值**: 把"他不爱我/她太粘人"的道德叙事，改写为"两个依恋系统的激活水平差"。

## 3. 批判 (Critical Appraisal)

- 证据基础: 成人依恋维度模型 (Brennan 两维) 有强实证支持；但本书面向大众，部分案例为合成。
- 风险: 标签化 (把伴侣判成"回避型所以无解") 是最常见误用；依恋风格是连续维度不是诊断。
- 盲点: 本书对家庭暴力、虐待语境下的"回避"几乎不讨论 — 必须在 B 段红线中显式排除。
- 跨文化: 亲密距离的文化规范不能被粗暴归因为依恋维度。

## 4. 应用 (Application Outline)

- 用户场景: "他一不回消息我就慌" / "她总说需要空间" / "我们为什么越吵越远"
- 关键任务清单 (用于覆盖审计):
  1. 识别自己和伴侣的依恋风格坐标
  2. 识别焦虑型激活策略 (protest behavior)
  3. 识别回避型去激活策略 (deactivation)
  4. 理解 IWM 如何驱动关系选择
  5. 理解童年分离焦虑到成人依恋的传导
  6. 理解依恋与共情的交互
  7. 用关系正念/伴侣支持缓冲不安全感
