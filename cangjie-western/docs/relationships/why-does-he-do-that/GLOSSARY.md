# GLOSSARY — Why Does He Do That?

| 术语 | 英文 | 定义 |
|---|---|---|
| 权利感 | Entitlement | 施虐者相信他有权从女性那里索取性、家务、顺从，并在她拒绝时强制执行的内化信念。 |
| 被困 | Entrapment | 威胁、隔离、经济、孩子四来源构成的离开障碍；受害者不离开不是因为自虐。 |
| 归罪转移 | Blame-shifting | 施虐者把自己的暴力/控制行为责任内推给受害者的叙事机制。 |
| 煤气灯操纵 | Gaslighting | 让受害者怀疑自己的记忆、感受与理智（"你反应过度""你疯了"）。 |
| 致命因子 | Lethality factors | Campbell/Websdale/Adams 研究中预测亲密伴侣杀人风险的可观测项。 |
| 掐颈 | Strangulation | 亲密暴力中最强的杀人预测因子之一；任何一次都升级安全优先级。 |
| 跟踪/盯梢 | Stalking | 极端嫉妒与监控行为，常先于致命暴力。 |
| 施暴者干预项目 | Batterer Intervention Program (BIP) | 唯一有证据支持的男性改变路径；不同于普通心理咨询。 |
| 经济控制 | Economic abuse | 通过控制收入、不让工作、查每笔支出把受害者锁在关系里。 |
| 隔离 | Isolation | 施虐者切断受害者与朋友、家人、同事的联系，使其缺乏外部视角。 |
| 改变神话 | Myth of change | 受害者用"他会改"合理化留下；道歉/承诺/普通咨询不构成改变证据。 |
| 施虐者 vs 自恋者 | Abuser vs Narcissist | Bancroft 区分：施虐者学来权利感、暴力只针对伴侣孩子；自恋者有童年创伤、对所有人剥削。 |
| 安全计划 | Safety plan | 逃生路线、备用钥匙证件、暗号、秘密账户、告知工作/亲友、报警备案。 |
| 5:1 对照 | — | 本卡书不使用；与 Gottman 七原则的 5:1 积极-消极比形成"危险识别 vs 健康构建"对照。 |
