# DIGEST — The Seven Principles for Making Marriage Work 精华长文

## 一句话

婚姻幸福不靠找对人或不吵架，而靠可工程化的日常互动：正性互动 ≥5:1 缓冲、不出四骑士、修复尝试能被接住、持续了解对方的内在世界。

## 三个最该记住的判断

1. **好夫妻也吵——差别在修复。** 婚姻可以扛过"末日四骑士"，前提是双方学会有效修复。修复尝试持续失败 = 不幸未来。任何——哪怕很傻——能阻止升级的言行都是修复尝试；先接住，再谈对错。
2. **蔑视是离婚头号预测因子。** 批评→蔑视→防御→筑墙是一条升级链。一旦出现讽刺、翻白眼、"你就是不行"，必须叫停并替换为欣赏文化。
3. **被记住，就是连接。** 爱情地图不是问卷，是持续好奇：他这周在怕什么？他上周说的那个事后来怎样了？"你根本不了解我"= 地图太薄。

## 九张能力卡速查

| 卡片 | 一句话决策规则 |
|---|---|
| four-horsemen | 批评→蔑视→防御→筑墙；蔑视是离婚头号预测因子。 |
| thermostat-ratio | 过热/过冷都要重置；正负互动比 ≥5:1。 |
| repair-attempts | 任何阻止升级的言行都是修复；先接住救生圈。 |
| love-maps | 幸福伴侣不是更爱，而是更知道对方在想什么。 |
| repair-recovery | 背叛后处理伤害→重建信任→处理触发点。 |
| passion-decline | 未被听见的话会自己找耳朵；向内对话替代向外倾诉。 |
| money-talk | 从"我们彼此对立"改为"我们对问题"。 |
| plan-partnership | 关系像企业：愿景+分工+月度复盘。 |
| emotion-coaching | 命名→验证→设边界→找解；冲突是教学窗口。 |

## 与其他书的关系

- **上游/危险侧**：Why Does He Do That（Bancroft）识别"这段关系有没有危险/控制"。
- **下游/健康侧（本书）**：Gottman 七原则构建"双方善意关系如何经营"。
- **互补框架**：EFT（Hold Me Tight）提供情绪层恶化循环；Imago（Getting the Love You Want）提供无意识配对。三者关系：Gottman 看行为互动，EFT 看情绪依恋，Imago 看童年脚本。
- **关键边界**：若 four-horsemen 中出现威胁/暴力/控制，立即切到 Why Does He Do That 的 danger-lethality，不用本书工具。
